# 0029：社区插件全部改为用户手动安装

- 日期：2026-08-30
- 状态：已接受
- English：[0029](0029-manual-community-plugin-install.md)

## 背景

`v0.1.1-rc.2.shell.12` 误把测试阶段使用的社区插件策略做成了产品默认行为：
`dshmarket`、Better Sidebar 和任务看板被列入随包 Harness 闭包，且新 profile
首次启动会自动播种。用户看到的两个精选扩展可能只是测试安装结果，但发布包确实
带有这些包，这会把社区插件误认为官方内置功能。

## 决策

- 随包 Harness 闭包只保留官方 Harness bundle 和壳自有的
  `dsh-desktop-controls`，不包含任何社区插件。
- 删除首启 curated seeding；新 profile 只由 Harness 创建官方 bundle 清单。
- 保留扩展设置中的「安装插件市场」入口。用户主动安装 dsh-market 后，才能在
  Harness「设置 → 插件市场」中继续按需安装其他社区插件和主题。
- 不自动修改或删除已有 profile。测试阶段已经写入用户目录的插件仍由用户在
  「设置 → 插件」中自行卸载。

## 后果

- 安装包更小，安装后的插件清单完全由用户决定，社区插件不会被误报为官方功能。
- 首次使用插件市场多一步手动安装 dsh-market，但网络安装、来源确认和构建脚本授权
  都由用户明确触发。
- ADR 0024 保留为历史决策记录；本 ADR 对其“首启预装”部分作废并取代当前实现。
