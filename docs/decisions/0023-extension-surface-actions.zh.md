# 0023:扩展面只放扩展动作

- 日期:2026-08-29
- 状态:已接受
- English:[0023](0023-extension-surface-actions.md)

## 背景

扩展入口浮层把真正的扩展动作(设备配对)和通用应用功能混在一起:
切换全屏、打开日志、导出诊断。同时应用菜单的「扩展」子菜单和托盘菜单
各自又是不一样的子集——三个扩展面互不一致,非扩展项挤占了浮层。

## 决策

每个扩展面——扩展入口浮层、应用「扩展」菜单、托盘菜单——暴露同一组
三元动作:

- 连接设备(局域网配对);
- 安全模式(启动/退出,反映当前状态);
- 关于。

全屏是窗口功能,由系统视图菜单承担,不是扩展。日志与诊断属于维护入口,
作为按钮收进「关于」对话框。崩溃恢复页保留自己的日志/导出按钮:崩溃时
它是唯一可达的面。

## 后果

- 正面:浮层、「扩展」菜单、托盘一个心智模型——同样三个动作、同样顺序;
  「关于」成为唯一的诊断入口;
- 负面:从托盘到日志多两次点击(托盘 → 关于 → 打开日志);
  `toggleFullscreen` 桌面动作与 preload 桥白名单条目移除(已无调用方)。

## 备选方案

- 托盘和帮助菜单同时保留日志/诊断:每个动作三处重复,扩展面再次漂移
  ——否决;
- 浮层保留全屏:那是系统窗口功能,不是扩展——否决。
