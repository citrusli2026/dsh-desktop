# 0044：把鲸鱼挂件作为可选的内置插件

- 日期：2026-10-24
- 状态：已接受
- English：[0044](0044-builtin-whale-widget.md)

0043 让壳能承载插件声明的伴随窗口，但用户仍要自己找到并安装 `dsh-whale-widget`。维护者随后要求把它
做成**开箱可见、可一键关闭**的能力，同时保留原作者的署名与上游入口。直接内置整个第三方插件与 0030
「不做桌面宠物」的排除项冲突，所以本决策把范围收得很窄：

决策：把一个**经过审阅的社区插件副本**随壳分发，**默认开启**，用户可在「桌面设置 → 扩展 → 小鲸鱼
桌宠」随时关闭。

- **上游代码不改**：`third_party/dsh-whale-widget` 是**未经修改的上游 0.4.2**；壳自己提供两样东西：
  已知包的伴随窗口描述（`src/main/companion-compat.ts`，按 0.4.x 版本门控）和由
  `dsh-desktop-controls` 宿主提供的适配页（`/__dsh-desktop/whale-pet`，加载插件自己的
  `/dsh-whale/widget.js`）。插件若将来自己声明 `dsh.companion`，声明优先，适配层自动让位。
  `VENDORED.md` 记录版本与素材许可，安装包不跟随 npm 更新。
- **默认开启、可关闭**：偏好 `whaleWidgetEnabled` 缺省 true（缺省文件视为开启）。关闭时壳不把补丁交给
  加载器，并移除自己创建的 profile 符号链接，因此插件管理器、伴随窗口与面板都看不到它。
- **只有偏好开关能挂载**：`prepareWhaleMount()` 在每次 Harness 启动时按偏好决定，**Safe Mode 一律
  不挂载**（与「第三方插件已隔离」的承诺一致）。开关需要重启 Harness 生效，设置页给出显式按钮。
- **不改用户 profile**：通过壳自有的 `--patch` 参数与 profile 内的符号链接接入，与
  `dsh-desktop-controls` 同一套机制；用户自己安装的同名包优先，壳不覆盖真实目录。
- **署名与边界**：设置页写明「原作者 MeteorNOX」并提供上游项目链接；审批仍只在主窗口完成（0030/0043
  的边界不变），壳不因内置该插件而获得审批桥。
- **素材许可**：代码 MIT，但 `assets/**` 按上游 `PROVENANCE.md` 是 as-is 分发、不再许可。本决策只
  允许随这个插件副本原样分发，不把素材纳入 dsh-desktop 的 MIT。

后果：用户无需安装即可体验，关掉后行为与之前完全一致；壳承担一个第三方插件的集成与回归（内置用例 +
外部 opt-in 用例），并在 Safe Mode 下自动排除。兼容判断读取**实际挂载的版本**（`profiles/node_modules`
里壳的挂载链接），因此用户 web profile 里残留的旧版（如 0.2.10）不会把伴窗静默关掉。被否决的方案：
始终挂载且不可关闭（用户无法恢复原样）；把插件代码重写进壳（维护两份实现）；自动从 npm 更新
（第三方更新会绕过壳的审阅）。
