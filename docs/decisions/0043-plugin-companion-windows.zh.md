# 0043：由已安装插件声明的伴随窗口

- 日期：2026-10-23
- 状态：已接受
- English：[0043](0043-plugin-companion-windows.md)

ADR 0030 把「桌面宠物」列在壳不做的事情里。外部需求 #130（dsh-whale-widget）暴露的真实诉求更宽也更
合理：用户最小化主窗口后，插件的常驻状态跟着消失，希望插件自己的界面能留在桌面上。继续用「宠物」
这个标签一概拒绝，会让壳错过一类它能安全承载的插件界面。

决策：壳提供**通用的伴随窗口能力**，每个伴随窗口由已安装插件自行声明。插件在自己的 `package.json` 里
选择加入：

```json
"dsh": { "companion": { "route": "/dsh-whale/pet", "width": 560, "height": 620, "title": "小鲸鱼", "showOnMinimize": true } }
```

能力被刻意收窄：

- **只读发现**：壳扫描当前 Web profile 的 `node_modules/*/package.json` 读取声明，不导入、不执行、
  不检查插件代码。
- **仅同源路径**：`route` 必须是以 `/` 开头的绝对路径（禁止 scheme、`//`、`..`、查询串与 fragment），
  在 Harness 源上加载，只转发登录 token。
- **先探测再显示**：路由必须 4 秒内返回 2xx 且 `text/html`，否则不创建窗口——声明了却没有页面的插件
  不会留下一块透明残窗。
- **沙箱窗口**：`sandbox` + `contextIsolation`、无 `nodeIntegration`、拒绝 `window.open`，导航与重定向
  锁定在声明路径。
- **不提供 Agent 桥**：伴随窗口的 preload 只暴露「隐藏自己」和「聚焦主窗口」。壳不读 Harness DOM、
  不调用 `executeJavaScript`、不提供审批动作；审批仍留在主窗口。
- **生命周期**：声明了 `showOnMinimize` 的伴随窗口在主窗口最小化时出现，恢复/显示/隐藏/关闭时收起；
  跟随 `display-metrics-changed` 重新定位；退出时销毁。位置为主窗口所在显示器的右下角，多个伴随窗口
  依次错开。
- **面板开关**：桌面工具面板列出已声明的伴随窗口，通过两个带发送方校验的 IPC
  （`companion:list`、`companion:toggle`）开关。

本决策**仅**在本能力范围内取代 ADR 0030 对「桌面宠物」的一刀切排除；不引入 Agent 工作台、第二套聊天
界面或由壳渲染插件内容。它也取代 #130 补丁的构建产物替换式分发：替换 `app.asar` 并关闭自动更新与
「可靠、可更新」的壳不相容，而声明式契约可以跨版本存活。

后果：插件作者增加一个清单字段和一条已注册路由，用户无需环境变量或重打补丁就能得到窗口；壳承担声明
解析、路由探测和第二套窗口生命周期，由 policy/discovery 单测与「真实壳最小化→出现→focusMain→恢复」的
打包端到端用例覆盖。被否决的方案：硬编码 `/dsh-whale/pet` 与插件的 CSS 类名（厂商耦合，插件改版即静默
失效）；用 iframe 承载（无法在窗口最小化后存活）；由渲染层提供审批桥（把壳变成审批面，且依赖不可抓取的
DOM）。
