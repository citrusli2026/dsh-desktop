# 0030：可靠 Electron 壳与开箱即用范围

- 日期：2026-08-30
- 状态：已接受
- English：[0030](0030-reliable-electron-shell-scope.md)

## 背景

`dsh-desktop` 是社区维护的个人项目，资源有限。桌面端的价值是让官方
DeepSeek Harness 更容易安装、启动、长期运行和恢复，而不是重新做一个 Agent
工作台。若持续跟随其他项目加入多 Agent、文件工作区、浏览器、视觉和大量模型
适配，范围会超过社区项目能够稳定维护的边界。

## 决策

产品定位固定为：**可靠的 Electron 壳，加上开箱即用的支持**。

壳层优先负责：

- 自带 Node 和 Harness 依赖闭包，下载后即可启动；
- 原生窗口、托盘、菜单、单实例、进程监督和桌面偏好；
- 更新提示、内核选择/回滚、诊断导出、安全模式和恢复中心；
- 社区插件的手动安装入口、状态展示和故障恢复支持；
- 在已有范围内打磨跨平台、网络、路径、语言和首次启动体验。

Harness 继续负责 Agent、会话、工具、模型和插件的核心行为。壳不另做 Agent
工作台、独立聊天产品或第二套会话模型。

以下内容不属于当前范围：

- Agent 工作台、独立聊天界面、多 Agent 编排；
- 复杂项目/worktree 管理、文件 diff 工作区和 Agent Browser；
- Vision、默认屏幕捕获、桌面宠物、游戏化和大规模主题系统；
- 多模型聚合、本地模型生命周期管理和互联网远程控制平台。

社区插件继续全部由用户手动安装，不进入安装包，也不在首次启动自动播种。
签名和公证暂不作为当前迭代或发布门禁；在主要功能完成后，根据真实下载量、
活跃使用量和用户反馈决定是否启动单独的签名专项。

## 后果

- 维护范围可控，测试和发布质量优先于功能数量。
- “开箱即用”指安装、启动、恢复和进入官方 Harness 的路径顺畅，不等于预装社区插件。
- 新功能必须直接改善可靠运行、安装体验、恢复能力或桌面使用体验，否则进入非目标清单。
- 未来若用户规模证明签名/公证有必要，可以作为独立发布基础设施项目，不影响当前架构。

## 备选方案

- **跟随竞品扩展成 Agent 工作台**：否决，维护成本和产品责任超出社区个人项目边界。
- **现在优先购买签名/公证**：暂缓，当前更需要完成已有功能；使用量不足以证明投入回报。
- **继续预装精选社区插件**：否决，社区插件必须由用户明确选择和安装，避免把测试内容误认为官方功能。
