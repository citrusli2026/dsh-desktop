# 0035：Host 权威协调的会话垃圾桶事务

- 日期：2026-10-11
- 状态：已接受
- English：[0035](0035-host-owned-session-trash.md)

只移动会话目录会留下 Host 驻留 Session 和 Client 选中的旧详情。固定内核已有刷新/归档能力，
没有安全移除接口；只有创建该 Agent 的 API Session 所有者持有 `AgentHandle.dispose()`。
过滤列表、重启或直接修改私有 registry 都会掩盖生命周期缺陷。

在**内置闭包**交付受版本约束、纳入版本控制的窄范围生命周期扩展：原创建方保留 Handle，
占用空闲维护阶段、移动前 flush，并只释放该方拥有的确切空闲实例。运行/排队任务、并发激活、
其他 writer/owner 都拒绝；冷会话通过持久化服务持有跨进程写锁直到操作结束。UI 选择所有者释放
明确标记 removed 的主视图引用，桌面插件不改导航私有状态。归档修改走 Host 服务，不写 workspace.json。

这是 ADR 0005“与上游逐字一致闭包”的明确、有限例外。deploy/build 自动执行补丁，重复执行不改结果，
未知版本/锚点使构建失败。不升级依赖、不创建第二份会话数据库、不修改用户安装的 overlay 内核。
不具备该能力的 overlay 应拒绝删除，切回内置内核是安全路径。未来上游提供公开能力后，在等价所有权、
故障与真实侧栏回归通过的前提下移除本地扩展。

主窗口 Harness sender guard 仍是授权边界。主进程以不进入 renderer/日志的随机应用期 token 调用
私有 loopback Host 通道，每次子进程边界都使端点失效。Host 串行操作，复用与主进程相同的磁盘工具。
资源通知携带 home 与身份；客户端拉取权威状态，丢弃过时面板读取。同步失败可重试，不能显示完全成功。

真实 Electron/Harness 回归使用临时 home 和本地模拟模型，核对真实标题行与选中详情的删除/恢复/
取消归档，并证明活动任务被拒绝而非停止。会话恢复冲突/回滚及更广的并发属于独立 TR-03 任务。
