# dsh-desktop v0.1.6-alpha.1.shell.0

DeepSeek Harness 社区桌面版 · 内核升级并锁定官方 `@deepseek-ai/dsh` `0.1.6-alpha.1`（壳修订归零）。

## 本次更新

- **内核升级**：随官方 `@deepseek-ai/dsh` `0.1.6-alpha.1`（上一内置内核 0.1.5-rc.2）。上游变更内容见 [官方发布页](https://github.com/deepseek-ai/deepseek-harness/releases)。
- **依赖闭包同步**：上游本轮补齐了 `dsh-client-ui-sidebar-documentpreview@0.1.6-alpha.1`（此前 #48 记录的断链），新内核 peer 缺口 `@deepseek-ai/dsh-ptc-runtime` 已加入闭包清单；10 个未随新内核发版的 dsh-* 包按解析版本保留，避免版本倾斜。
- **壳层工具修复**：`version.mjs bump dsh` 的 peer pin 同步此前只发生在内存、从未写盘（本轮首次真实内核升级暴露），已修复并补注册表可用性检查——未发新版的包不再被改写成不存在的范围。
- **验证**：283 项单测、双树 npm 审计零已知漏洞、dev E2E 16/16、打包冒烟（含真实 Harness UI 渲染与 Safe Mode 故障注入）、离线 + 真实市场 E2E、LAN 扫码全部通过；本发布继续执行三平台构建、attestation 核验与跨版本升级门禁。
- **边界说明**：桌面壳无功能变更；社区插件仍不进入安装包。若插件与新内核不兼容，启动失败时错误页提供一键「升级 / 禁用」恢复。

## 验证

- Release 门禁：verify（283 项单测 + E2E）、macOS/Windows/Linux 构建、packaged smoke（真实渲染 + 安全模式注入）、attestation、跨版本升级数据保留、离线/真实市场与 LAN 扫码。

## English Summary

- Kernel bump: bundled `@deepseek-ai/dsh` locked to `0.1.6-alpha.1` (previous 0.1.5-rc.2); shell revision reset to 0. See the [official upstream release notes](https://github.com/deepseek-ai/deepseek-harness/releases) for kernel changes.
- Upstream completed the missing `dsh-client-ui-sidebar-documentpreview@0.1.6-alpha.1` publish (issue #48); the new `dsh-ptc-runtime` peer joined the closure, and packages that did not ship a 0.1.6-alpha.1 build stay at their resolved versions to prevent version skew. A shell tooling fix now persists kernel peer-pin syncs (they previously lived only in memory) and checks registry availability before rewriting ranges.
- Desktop shell unchanged. If a community plugin is incompatible with the new kernel, the error page offers one-click Update / Disable recovery.
