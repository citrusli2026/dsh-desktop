# dsh-desktop v0.1.2-rc.1.shell.6

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-rc.1`（未变，壳修订 +6）。

## 本次更新

- **修复扫码配对后手机提示需要重新认证**：内核 0.1.2-alpha.2 起，`dsh web` 首页只在携带单次启动令牌或签名 cookie 时提供，配对成功后手机加载界面会收到内核的 401（"dsh web authentication required"）。桌面版现在把就绪 URL 中的启动令牌交给配对代理（dsh-mobile-shell 1.0.1），由代理换取签名会话 cookie 并附在转发请求上；内核重启时代理随之自动重启轮换令牌。手机端仍然只对桌面版代理认证，不接触内核令牌。
- **修复 Windows 右上角按钮重叠**：Windows/Linux 的原生最小化/最大化/关闭按钮区域会压住内核会话头部右上角的「Session log」导出按钮。桌面版在该两平台隐藏该胶囊按钮；同样的导出能力仍可通过 `/export` 斜杠命令使用。
- **边界说明**：代理只对上游出示自己换取的会话 cookie，不向手机下发内核令牌；隐藏按钮不减少任何功能入口。

## 验证

- 单元测试 213 通过（新增：启动令牌向代理传递的断言；以仿内核上游驱动真实代理，覆盖无令牌 401 透传、cookie 交换与复用、上游换密后强制重换并重放三条路径）；`pnpm run verify` 全绿。
- E2E 15 通过（含 LAN 配对二维码本机门禁）；随版本物化的 dsh-mobile-shell Web 产物为 1.0.1。

## English Summary

- Fixed "dsh web authentication required" on phones after LAN pairing: the shell now hands the ready-URL launch token to the pairing proxy (dsh-mobile-shell 1.0.1), which exchanges it for the kernel's signed session cookie and presents it on forwarded requests; the proxy restarts with the token on kernel restarts.
- Fixed the session-log export capsule overlapping the native min/max/close controls on Windows/Linux: the capsule is hidden there and the same export remains available via the /export command.
