# dsh-desktop v0.1.5-rc.2.shell.1

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.5-rc.2（未变，壳修订 +1）。

## 本次更新

- **启动失败识别更准**：修复插件因调用新内核 API 而崩溃时的归类——这类"插件与内核版本不匹配"的崩溃此前不会被识别，错误页不给针对性说明；现在会明确提示保持插件禁用、等待插件适配，避免无效的反复升级。
- **体检能发现损坏的内置 Node**：「一键运行体检」现在校验内置 Node 可执行文件的完整性；升级残留或安全软件改写导致的文件损坏（启动报 spawn 错误）会被直接指出并建议完整重装，不再误报正常。
- **错误页自救指引**：内置 Node 启动失败（spawn 错误）时，错误页直接说明文件已损坏/缺失并引导重装（会话与设置保留），而不是只显示错误码；诊断报告也会记录该状态便于求助。
- **边界说明**：局域网配对密钥、设备登记、插件恢复、桌面垃圾桶和诊断仍只保存在本机，不上传用户数据。

## 验证

- 250 项单元测试（新增 6 项覆盖上述识别与校验）；`verify` 全绿，16 项开发态 E2E、打包态 smoke、真实 Harness UI 渲染、离线与真实插件市场、本机 LAN 扫码配对均通过。
- 根依赖树与 Harness 生产依赖树安全审计均为 0 已知漏洞；发布工作流继续执行 macOS / Windows / Linux 构建、跨版本数据保留、8 资产契约与 attestation。
- GitCode 国内镜像和官网版本数据在三平台产物发布后同步并逐项在线校验。

## English Summary

- Classifies plugin-vs-kernel API crashes (runtime type errors inside loader failures) so the error page gives the right guidance instead of a bare error.
- The one-click health check now validates the bundled Node executable's integrity, catching upgrade-residue and antivirus damage that previously read as healthy.
- The error page explains runtime spawn failures and calls for a clean reinstall; the diagnostics report records the state for support.
