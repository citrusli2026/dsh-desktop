# dsh-desktop v0.2.1-alpha.1.shell.5

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-alpha.1（未变，壳修订 +1）。

## 本次更新

- **飞书一键连接**：原生扩展菜单提供独立的“配置飞书机器人”二维码流程，选择工作区、扫码确认后自动保存受保护凭证并尝试启动 cc-connect。
- **官方 Feishu skills**：新增 `pnpm run feishu:setup`，通过官方 `@larksuite/cli` 安装 `lark-*` skills 并完成用户 OAuth；用户 CLI 身份与 cc-connect 机器人身份保持分离。
- **安全边界**：二维码流程只使用临时配置目录，App Secret 不进入窗口、配置 TOML、状态、日志或仓库；退出、取消和超时都会清理临时数据。

## 验证

- 类型检查、文档契约、站点检查、扩展菜单二维码 Electron E2E、cc-connect 配置/Sidecar 假实现和本地 ACP mock 均通过；完整发布门禁在 tag 后由 CI 复跑。
- 官网中英文首页与安装指南已更新，GitHub/GitCode 安装器镜像和线上 release 数据将在发布流程中逐项验证。
- 真实飞书手机回调仍需组织账号完成最终人工验收；自动化使用假 Secret、临时目录和模拟 ACP，不连接真实凭证。

## English Summary

- Add a native Extensions / Desktop tools QR flow for setting up a Feishu bot, saving protected credentials, and starting cc-connect for the selected workspace.
- Add `pnpm run feishu:setup` through the official `@larksuite/cli` installer to provision `lark-*` skills and user OAuth while keeping CLI and bot identities separate.
- Keep App Secrets out of the window, TOML, status, logs, and repository; clean temporary setup data on success, cancellation, or timeout.
- Update the Chinese and English website home/install pages; automated tests use fake secrets, temporary directories, and a local ACP mock. Real Feishu callback acceptance remains an organization-account QA step.
