# dsh-desktop v0.1.7-rc.1.shell.1

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.7-rc.1（未变，壳修订 +1）。

## 本次更新

- 修复内核 0.1.7 迁移旧版设置后，原生菜单、窗口标题、托盘等桌面界面语言回退到操作系统语言的问题。壳现在优先读取 `web` profile 中的语言和主题偏好，并跟随 profile 更新。
- 保留迁移兼容：仍可读取现存的 `settings.yaml` 及内核归档的 `settings.yaml.imported`；读取旧归档时不会重新创建旧设置文件。
- 偏好留在本机 Harness profile 中，不会上传。
