# dsh-desktop v0.1.7-rc.2.shell.1

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.7-rc.2（未变，壳修订 +1）。

本轮为 **macOS 启动修复（#79，关键）+ 登录流程端到端加固 + 局域网多地址二维码（#65）**。

## 本次更新

- **修复 macOS 无法启动（#79，关键）**：v0.1.7-rc.2.shell.0 的 macOS 版本因完整性清单文件在代码签名**之后**写入而破坏 ad-hoc 封印，macOS 判定应用「已损坏」拒绝启动。本轮起 macOS **不再打包清单文件**（它会破坏封印，二者不可兼得）——macOS 的完整性改由**代码签名本身**校验（`codesign --verify --deep --strict`，运行体检自动执行），比 SHA-256 清单更强。shell.0 的 macOS 用户请务必升级到本版；Windows/Linux 不受影响，清单校验照旧。
- **左下角登录流程端到端验证与加固**：账号弹层 → 登录 → 授权页自动打开的全链路已有打包 E2E 覆盖并全绿；随 rc.2 重建的登录授权自动打开补丁完成端到端验证（本迭代在真实安装包上复现并修复了该补丁的 effect 顺序问题——插入位置在声明之前会引发渲染期错误，登录对话框无法打开）。
- **局域网多地址二维码（#65）**：配对窗口现在按可达地址渲染**多个二维码**并标注类别（局域网 / VPN 虚拟网卡），Tailscale/ZeroTier 与物理局域网的设备都能扫到属于自己的入口；同一地址自动去重，最多展示 4 个。
- **内核与边界不变**：内置内核仍为 0.1.7-rc.2；不新增权限、不改变数据目录边界。

## English Summary

- Critical macOS launch fix (#79): v0.1.7-rc.2.shell.0 shipped the closure manifest after the ad-hoc seal, so macOS reported the app as damaged. macOS builds no longer ship a manifest — integrity on macOS is now enforced by the code signature itself, verified at runtime via `codesign --verify --deep --strict` in the health check. macOS shell.0 users must update.
- The bottom-left account-popover login flow (popover → Sign in → authorize URL) is covered end-to-end by packaged E2E, including the rc.2-rebuilt auto-open patch.
- The LAN pairing window now renders one QR code per reachable address, labeled LAN vs VPN virtual adapter (#65 follow-up). Bundled kernel unchanged at 0.1.7-rc.2.
