# dsh-desktop v0.1.5-rc.1.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.5-rc.1（0.1.5 线首个 RC，壳修订归零）。

## 本次更新

- **内核升级**：随包 Harness 从 0.1.5-alpha.1 升至 0.1.5-rc.1，同步全部 31 个直接 peer 契约、锁文件与供应链豁免清单（241 条）。
- **移动接力探测说明**：rc.1 的 Web 界面启动时会探测移动接力通道（`api/remote.mux`）；未开启"连接移动设备"共享时该探测会在开发者控制台留下一条连接拒绝消息，页面功能不受影响。
- **边界说明**：局域网配对密钥、设备登记、插件恢复、桌面垃圾桶和诊断仍只保存在本机，不上传用户数据。

## 验证

- 244 项单元测试；`verify` 全绿，16 项开发态 E2E、打包态 smoke、真实 Harness UI 渲染、Safe Mode、离线与真实插件市场、本机 LAN 扫码配对与 Android 15 模拟器真实 Chrome 全链路均通过。
- 根依赖树与 Harness 生产依赖树安全审计均为 0 已知漏洞；发布工作流继续执行 macOS / Windows / Linux 构建、跨版本数据保留、8 资产契约与 attestation。
- GitCode 国内镜像和官网版本数据在三平台产物发布后同步并逐项在线校验。

## English Summary

- Upgraded the bundled Harness kernel to 0.1.5-rc.1 and realigned all 31 direct peer contracts, the lockfile, and the supply-chain allowlist.
- rc.1's WebUI probes the mobile handoff mux at startup; without LAN sharing enabled the probe leaves one console message and the page stays fully functional.
- Revalidated the full local gate battery, both dependency audit trees (zero known vulnerabilities), and the Android emulator pairing journey.
