# dsh-desktop v0.2.1-rc.2.shell.9

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-rc.2（未变，壳修订 8 → 9）。

## 本次修复

- **修复 shell.8 的小鲸鱼被页面盖住、点击穿透**：上一版为了不遮挡「桌面工具」入口，把
  `.dshwv-root` 压到 `z-index: 1`。Harness 的应用根是一个层叠上下文，压低后小鲸鱼实际被聊天页
  盖住，点击也落到下面的页面上。现在恢复它原本的 body 层级（`z-index: 9999`），小鲸鱼重新可见、
  可点击（点开余额/菜单）。
- **不再需要“压低层级”**：改为在 Harness 弹窗（设置等）和桌面工具面板打开时隐藏小鲸鱼
  （`body:has([role="dialog"])` / `body:has([data-dsh-desktop-controls-panel])`），弹窗与面板始终
  可点，同时不影响小鲸鱼本身。
- **修复伴窗尺寸不同步**：适配页之前把 `--dshw-scale` 写死成 `1.6`，与用户在网页端保存的尺寸
  （例如 `0.6`）不一致；现在移除该覆盖，主窗口与最小化后的伴窗都读取同一份
  `.dshw-size.json` 缩放值。
- **回归覆盖**：内置鲸鱼 E2E 新增断言——主窗口层级必须为 9999、缩放必须等于保存值、真实点击能
  打开菜单、打开设置时小鲸鱼隐藏、伴窗缩放与主窗口一致。

## 验证

- `pnpm run typecheck`、`pnpm run test`（537 通过）、`pnpm run build` 通过；
- 打包端到端：内置鲸鱼 3/3（含新增层级/点击/缩放断言）、通用伴窗 2/2、外部鲸鱼 1/1、
  UI review 4/4、垃圾桶 UI、LAN 2/2；
- 手工复现用户场景（保存 scale=0.6）：主窗口小鲸鱼完整可见、`elementFromPoint` 命中
  `.dshwv-img`、点击打开菜单、设置弹窗打开时隐藏、伴窗同为 0.6。

## English Summary

- **Fix the shell.8 whale regression**: lowering `.dshwv-root` to `z-index: 1` put it behind the
  Harness app root (a stacking context), so it was clipped and clicks fell through to the page. Restored
  its body-level `z-index: 9999`; the whale is visible and clickable again.
- **No need to lower it**: instead hide the whale while a Harness dialog or the desktop-tools panel is
  open, so those surfaces stay clickable without breaking the whale.
- **Fix companion size sync**: the adapter page hard-coded `--dshw-scale: 1.6`; removed, so the main
  window and the companion both use the saved `.dshw-size.json` scale.
- **Regression coverage**: the built-in whale E2E now asserts the 9999 layer, the saved scale, a real
  click opening the menu, hiding on Settings, and matching companion scale.
