# dsh-desktop v0.1.2-alpha.2.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-alpha.2`（内核升级，壳修订归零）。

## 本次更新

- 扩展设置收敛：移除设置页长期占位的运行状态区，把安全模式提升到首屏，把截图、插件市场、内核和预设等低频工具收进「更多壳工具」；当前平台不可用的选项不再展示。
- 官网展示重排：轮播统一为真实应用的 `2560×1720` 截图，中文/英文与明/暗主题一一对应；首页压缩重复说明，中文导航统一四字，并保留扩展设置、安全模式和手动安装社区插件的关键信息。
- 内核与闭包：升级并锁定 `@deepseek-ai/dsh` `0.1.2-alpha.2`，补齐新内核要求的显式 peer 依赖；社区插件仍不进入安装包，必须由用户主动安装。
- 产品边界：继续保持「可靠的 Electron 壳 + 开箱即用的支持」，不新增 Agent 工作台；签名与公证仍不作为本次门禁。

## 验证

- `pnpm run verify` 通过：类型检查、运行时边界、184 项测试（行覆盖率 92.34%、分支 83.43%、函数 87.40%）、官网/API 门禁和构建均通过；Harness bootstrap 通过 peer 审计。
- 本地真实包已通过 `dist:dir`、普通 packaged smoke、真实 Harness UI smoke、Safe Mode 故障注入恢复、1 项 packaged E2E；开发态 E2E 为 12 项通过、1 项条件跳过。三平台安装包、资产证明、GitCode 镜像和官网 release data 由发布流水线继续核验。

## English Summary

- Upgraded and pinned the bundled `@deepseek-ai/dsh` kernel to `0.1.2-alpha.2`, with the newly required peer dependencies explicitly included in the harness closure.
- Simplified Extensions settings: persistent runtime status is no longer shown there, Safe Mode is promoted to the primary recovery group, secondary shell tools are collapsed, and unsupported platform options are omitted.
- Reworked the bilingual website with matching real-app `2560×1720` screenshots for both locales and themes, shorter homepage copy, and consistent four-character Chinese navigation labels.
- The scope remains a dependable Electron shell with out-of-the-box support: community plugins are manual-only and never bundled, no Agent workbench is added, and signing/notarization remain deferred.
