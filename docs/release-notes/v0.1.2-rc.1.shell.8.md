# dsh-desktop v0.1.2-rc.1.shell.8

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-rc.1`（未变，壳修订 +8）。

## 本次更新

- **修复手机扫码后插件加载失败**：随包 dsh-mobile-shell 升至 `1.0.2`。代理现在原样保留 Harness `/plugins/??…` 批量资源路径，不再把第二个问号 URL 编码后转发成 404；二维码、一次性配对码、设备会话与内核登录令牌仍保持分层隔离。
- **补齐坏插件自动恢复闭环**：插件导致启动失败时，桌面端继续自动隔离并重启；恢复后的正常主页现在会显示问题插件和「升级并重新启用」按钮。该按钮只允许当前已验证的 Harness 本机页面调用，并继续拒绝官方包和未列入恢复上下文的包。
- **强化真实端到端门禁**：新增从桌面二维码到手机浏览器、再到真实 Harness 输入控件的打包测试，分别覆盖 Android 风格 Chromium 与 iPhone 风格 WebKit；同时用真实 npm 插件执行「崩溃 → 自动隔离 → 页面升级 → 重新启用 → 重启成功」。

## 验证

- 235 项单元测试通过；类型检查、运行时边界、覆盖率、官网数据契约与构建均通过。
- 本机真实打包扫码链路在 Chromium、WebKit 均通过；移动壳 24 个桌面/移动浏览器用例和完整 HTTP/WebSocket 冒烟矩阵通过。
- 真实 `dshmarket@latest` 安装与坏插件恢复通过；离线安装失败可解释且可重试；打包安全模式可隔离抛错插件并正常渲染。
