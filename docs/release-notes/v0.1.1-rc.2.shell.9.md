# dsh-desktop v0.1.1-rc.2.shell.9

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.1-rc.2（未变，壳修订 +9）。本版主题：**安全模式与救援闭环**——插件可以坏，工作台不能死。

## 本次更新

- **安全模式**：第三方插件启动失败会让 Harness 无法启动；现在错误页一键「以安全模式启动」（或从 ⋮ 扩展入口 / 扩展设置进入）。该模式下只运行官方 bundle 与内置扩展，第三方插件全部隔离；窗口顶部横幅常驻提醒，点击「退出安全模式」即恢复。标志持久化——重启后仍保持安全模式，坏插件不能在开机时再次击垮工作台。
- **恢复中心**：错误恢复页升级为四动作——重试 / 以安全模式启动 / 导出诊断 / 打开日志文件夹；自动检测插件加载失败时，页面与安全模式横幅直接点名**疑似插件（id + 包名）**，并引导到官方「设置 → 插件」卸载修复。
- **诊断报告增强**：新增插件清单（bundles、用户 bundle、组合行）、疑似坏插件候选、安全模式状态与内核/壳版本——排查「哪个插件坏了」不用再手动翻日志。
- **便携 Agent 预设（.dshpreset）**：「设置 → 扩展设置 → Agent 预设」可把预设导出为单个文件，另一台机器导入时带重名冲突检查（跳过 / 替换 / 克隆）与信任提醒；导入的预设走官方预设选择器，绝不覆盖内置预设。
- **打包门禁新增**：三平台 release 增加「坏插件 → 安全模式恢复」两阶段 packaged smoke（普通启动确证失败 + 安全模式恢复渲染与横幅）。
- **工程治理**：逐一评估并关闭 3 个不达标的依赖大版本 PR（@types/node 26 / electron 44.0.0 / esbuild 0.28），dependabot 收紧为 minor 范围；major 升级以「运行时升级专项」独立推进。6 个过期自动告警 issue 一并清理。
- 全部为本地壳功能：安全模式不删除、不移动任何插件文件；不读取屏幕、不做视觉识别、不上传数据。

## English Summary

- **Safe Mode** (decision 0021): when a third-party plugin keeps Harness from booting, start Safe Mode from the error page, the ⋮ panel, or Extensions settings — official bundles and built-in extensions keep running while user plugins are quarantined, with a persistent banner and an explicit "Exit Safe Mode" (the flag survives restarts so a bad plugin cannot re-brick the app at login).
- **Recovery center + diagnostics**: the error page now offers Retry / Start in Safe Mode / Export diagnostics / Open logs; on a detected plugin-load failure both the page and the banner name the suspected plugin id and package, pointing to the official Settings → Plugins manager. The diagnostic report additionally carries the plugin inventory, suspected plugins, Safe Mode state, and shell/harness versions.
- **Portable agent presets (.dshpreset)**: export a user preset as one file and import it elsewhere with conflict checks (skip / replace / clone) and trust warning; imports mount through the official preset picker and never replace built-in presets.
- **Packaged gates**: a two-stage Safe Mode smoke (broken plugin must fail the ordinary boot, then recover in Safe Mode with the banner rendered) now runs on all three platforms.
- **Dependency governance**: three unqualified major bumps closed (@types/node 26, electron 44.0.0, esbuild 0.28), dependabot capped to minor scope, majors move to a dedicated runtime-upgrade iteration; six stale auto-issues closed.
