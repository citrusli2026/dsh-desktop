# dsh-desktop v0.2.0-rc.1.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.0-rc.1（跨次版本升级，壳修订归 0）。

## 本次更新

- **内核升级 0.1.7-rc.2 → 0.2.0-rc.1**：跟随上游 0.2.0 线的首个候选版。壳侧闭包同步 34 个 `dsh-*` peer 钉、release-age 豁免清单重钉 229 项；登录授权自动打开补丁按新版本语义原样重建（上游 SignInDialog 仍未内置该能力）。
- **插件安装更安全（内核新行为）**：0.2.0 内核在插件安装时强制校验 peer 兼容性——与内核版本不匹配的旧插件会被明确拒绝并给出解释与风险豁免指引，不再静默装上后在运行时崩溃。社区插件市场（dshmarket）需 1.66.4 及以上版本才与本内核声明兼容；配套的 pnpm 11 供应链策略（新包发布满 24 小时才参与解析）意味着市场安装将在 1.66.4 发布满 24 小时后（2026-09-29 晚）自动恢复，此前安装会显示可重试的分类失败说明，无需用户操作。
- **升级与隔离契约延续**：跨版本升级冒烟（设置/数据保留断言）、插件损坏隔离（Safe Mode）在新内核上复验通过。

## 验证

## English Summary

- Kernel upgrade 0.1.7-rc.2 → 0.2.0-rc.1 (first 0.2.0 release candidate); 34 dsh-* peer pins synced, release-age excludes re-pinned (229), and the sign-in auto-open patch rebuilt against the new version.
- Kernel-side plugin installs now enforce peer compatibility: mismatched plugin versions are rejected with an explanation and an explicit risk-exemption path instead of crashing later. The community market (dshmarket) needs 1.66.4+ for this kernel; the bundled installer resolves to it automatically once published for 24 hours.
- Upgrade-path and broken-plugin isolation contracts re-verified on the new kernel; LAN pairing E2E and packaged smokes green.
