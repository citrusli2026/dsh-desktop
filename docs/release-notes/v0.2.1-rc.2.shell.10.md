# dsh-desktop v0.2.1-rc.2.shell.10

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-rc.2（未变，壳修订 9 → 10）。

## 本次更新

- **小鲸鱼桌面伴窗大小可单独配置**：设置 → 扩展 → 小鲸鱼桌宠新增「桌面伴窗大小」滑杆
  （80–400 px，默认 160）。它**只影响最小化后的桌面伴窗**，主窗口仍使用插件自己保存的缩放；
  重新最小化即生效，不需要重启 Harness。此前伴窗按视口公式取到 122 px 下限、又硬编码 1.6 倍，
  与主窗口差距很大。ADR 0047。
- **修复插件切换触发小鲸鱼重复路由、桌面端重启**（上游 #268）：内核会在销毁上一次执行前重新运行
  插件的 `apply`，小鲸鱼的精确路由第二次注册就会命中
  `webserver: duplicate exact route "/dsh-whale/image.png"`。壳的宿主插件现在先于第三方安装一层
  热重载安全的路由守卫：同一路径再次注册时先释放旧路由再注册新路由，不再抛错。插件代码仍未修改。
  ADR 0048。
- **升级 `@modelcontextprotocol/sdk` 1.31.0 → 1.32.0**（#122）：同步更新 `pnpm-workspace` 的
  安全覆盖与锁文件，重新部署闭包后 `sdk=1.32.0`、`jose=6.2.13`，peer 审计通过。仅依赖框架修复，
  无用户可见行为变化。
- **发布流程**：关闭 shell.8 失败自动单 #133 与已被通用伴窗取代的 PR #131；后续版本继续沿用
  “失败单在成功发布后处理”的约定。

## English Summary

- **The desktop companion now has its own size**: a slider under “Desktop settings → Extensions → Whale
  companion” (80–400 px, default 160) affects only the minimized companion; the in-window widget keeps
  its own saved scale, and re-minimizing applies it without a Harness restart. ADR 0047.
- **Fix a plugin-toggle crash** (upstream #268): Cordis re-runs `apply` before disposing, so the whale's
  exact routes hit `duplicate exact route` and the desktop restarted. The shell's host plugin now
  installs a reload-safe route guard before third-party plugins: re-registering the same path disposes
  the old route first. The vendored plugin stays unmodified. ADR 0048.
- **Bump `@modelcontextprotocol/sdk` 1.31.0 → 1.32.0** (#122), including the workspace security
  override and lockfile; the deployed closure reports `sdk=1.32.0` / `jose=6.2.13`.
- **Release housekeeping**: close the shell.8 failure issue #133 and the superseded PR #131.
