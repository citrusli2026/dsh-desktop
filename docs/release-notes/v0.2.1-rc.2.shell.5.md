# dsh-desktop v0.2.1-rc.2.shell.5

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-rc.2（未变，壳修订 4 → 5）。

## 本次更新

- **插件伴随窗口（ADR 0043）**：已安装插件可在自己的 `package.json` 里声明
  `dsh.companion { route, width, height, title, showOnMinimize }`，主窗口最小化后它的页面会作为独立桌面
  窗口留在右下角，恢复主窗口时自动收起。壳只读扫描当前 Web profile 的插件清单，不执行插件代码；显示前
  要求该路由 4 秒内返回 2xx `text/html`，不会留下一块透明残窗。
- **安全边界**：伴随窗口使用 `sandbox` + `contextIsolation`、无 `nodeIntegration`、拒绝 `window.open`，
  导航锁定在声明路径；只转发登录 token。预加载只提供「隐藏自己 / 聚焦主窗口」，壳不读 Harness DOM、
  不调用 `executeJavaScript`、不提供审批桥——审批仍只在主窗口完成。
- **面板入口**：桌面工具面板新增「伴随窗口」分组，列出已声明的伴随窗口并可手动开关；位置跟随主窗口
  所在显示器的变化，多个窗口依次错开，退出时销毁。
- **承接社区需求 #130**：小鲸鱼插件只需增加上述声明与 `/dsh-whale/pet` 路由即可获得该窗口，无需替换
  `app.asar`、无需关闭自动更新。契约见 `docs/companion-windows.md`。

## English Summary

- **Plugin companion windows (ADR 0043)**: an installed plugin can declare
  `dsh.companion { route, width, height, title, showOnMinimize }` in its own `package.json`; the shell
  discovers it read-only, probes the route for a 2xx HTML response, and hosts it in a sandboxed window that
  appears when the main window is minimized and hides when it is restored.
- **Security boundary**: sandboxed with context isolation, no Node integration, `window.open` denied,
  navigation pinned to the declared path; the preload only exposes hide/focus-main. No DOM access, no
  `executeJavaScript`, no approval bridge — approvals stay in the main window.
- **Panel entry**: a new “Companion windows” group in the desktop-tools panel toggles declared companions;
  placement follows the display containing the main window and windows are destroyed on quit.
- **Community request #130**: the whale widget only needs the declaration and its `/dsh-whale/pet` route —
  no `app.asar` patching and no disabling auto-update.
