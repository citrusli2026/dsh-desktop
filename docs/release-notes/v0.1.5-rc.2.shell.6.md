# dsh-desktop v0.1.5-rc.2.shell.6

Bundled kernel `@deepseek-ai/dsh` 0.1.5-rc.2 (unchanged; shell revision +6).

## Changes

- **Runtime upgrade: Electron 43 → 44 and the bundled Node runtime 22 → 24 LTS.** The harness child process now runs Node v24.21.0 (pinned from the official dist with per-platform SHA-256, same mirror-verified bootstrap), and the desktop shell runs Electron 44.3.0. CI workflows move to Node 24 so local, CI, and shipped runtimes agree. Native addons remain prebuilt Node-API modules, so no ABI rebuild is required.
- **Upgrade-residue analysis for the Windows installer**: docs/nsis-upgrade-residue-analysis.md documents how a damaged bundled `node.exe` (issue #39) can survive an NSIS upgrade, the mitigations shipped in shell.5, candidate fixes, and a six-case manual test matrix for Windows hardware.

## Verification

- Dev E2E 16/16, both packaged smokes (headless + real Harness UI) on Electron 44 + Node 24 with the packaged runtime verified as v24.21.0, market install E2E offline 1/1 and real 2/2.

- GitHub release assets, attestation, cross-version upgrade, and GitCode mirror checks run in the standard release pipeline.
