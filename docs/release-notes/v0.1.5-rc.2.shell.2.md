# dsh-desktop v0.1.5-rc.2.shell.2

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.5-rc.2（未变，壳修订 +2）。

## 本次更新

- **安全模式恢复更可靠**：修复一个首次启动时序问题——Harness 在写入 Profile 清单之前因坏插件崩溃时，安全模式可能枚举不到用户插件而无法自动禁用它。现在崩溃瞬间的插件嫌疑会记录在本地，重启后的安全模式即使读不到清单也能据此生成禁用清单，恢复不再依赖时序运气。
- **启动失败识别更准**：插件因调用新内核 API 而崩溃时（"插件与内核版本不匹配"），错误页会明确提示保持禁用、等待插件适配，避免无效的反复升级。
- **体检能发现损坏的内置 Node**：「一键运行体检」现在校验内置 Node 可执行文件的完整性；升级残留或安全软件改写导致的文件损坏（启动报 spawn 错误）会被直接指出并建议完整重装。
- **错误页自救指引**：内置 Node 启动失败（spawn 错误）时，错误页直接说明文件已损坏/缺失并引导重装（会话与设置保留）；诊断报告也会记录该状态便于求助。
- **边界说明**：局域网配对密钥、设备登记、插件恢复、桌面垃圾桶和诊断仍只保存在本机，不上传用户数据。

## English Summary

- Makes Safe Mode recovery deterministic: crash-time plugin suspects are persisted and drive the disable patch even when the harness crashed before writing the profile manifest.
- Classifies plugin-vs-kernel API crashes so the error page gives the right guidance instead of a bare error.
- The one-click health check now validates the bundled Node executable's integrity, and runtime spawn failures get an explicit reinstall hint on the error page and in the diagnostics report.
