# dsh-desktop v0.1.5-rc.2.shell.9

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.5-rc.2（未变，壳修订 +2）。

本轮为 **Windows 优先**的安装保真与损坏自愈轮：升级残留从"不可见的静默损坏"变为"安装器显式拦截 + 体检精确定位"。

## 本次更新

- **Windows 升级占用拦截**：升级安装器启动时检测旧的内置 `node.exe` 是否仍被占用（正在运行的 Harness、终端等），被占用即弹出中英双语提示"关闭后重试"，不再让复制失败被"忽略"成静默损坏；静默/自动更新场景以明确的退出码失败，而不是装出一个坏升级。
- **Windows 升级残留清理**：升级前清除旧安装运行目录的只读/隐藏/系统属性，旧卸载器可以真正删净全部随包文件；只读或被杀毒软件改写过的旧文件不再残留到新版本。
- **闭包完整性清单**：安装包内置全部随包文件的 SHA-256 清单。「运行体检」在原有快速检查之上做全量比对，发现被改动、缺失或多余的文件时直接给出具体文件路径与重装指引；「导出诊断报告」同步收录校验结论，方便贴到 issue 定位。
- **覆盖场景回归门禁**：新增 CI 残留矩阵——预置损坏、只读、占用三类 `node.exe` 后执行静默升级，断言损坏与只读文件必被替换、占用必须显式失败；闭包校验与篡改检测进入三平台打包冒烟。
- **工具链修复**：根因定位并修复 pnpm ≥10 在本仓库"lockfile 静默不落盘/安装挂死"的问题（版本委托到有缺陷的 pnpm 11.11 所致），包管理器固定为 pnpm 10.33.2；electron-builder 升至 26.16.1；Playwright 升至 1.63.0。
- **内核与边界不变**：内置内核仍为 0.1.5-rc.2；不新增权限、不改变插件安装与数据目录边界；体检保持只读、不上传、不自动修复。

- 打包门禁：闭包校验（干净树 ok + 篡改检出）、真实 Harness UI 渲染、安全模式两阶段、故障注入与重试恢复，mac 本地全绿；三平台构建与残留矩阵随发布流水线执行。

## English Summary

- Windows upgrades now fail explicitly with a bilingual dialog when the bundled `node.exe` is still in use, instead of silently producing a broken install; read-only/hidden leftovers from the old install are cleared so upgrades replace every bundled file.
- Installers embed a SHA-256 manifest of the whole bundled closure. The health check compares every file and names exactly which files were modified, went missing, or are unexpected (upgrade residue / antivirus rewrites); the diagnostics export includes the verdict.
- New CI residue matrix (corrupted / read-only / locked `node.exe`) and a closure-verify + tamper packaged smoke run on all three platforms for every release.
- Toolchain: pnpm pinned to 10.33.2 (root-causes the silent lockfile no-op and install hang), electron-builder 26.16.1, Playwright 1.63.0. Bundled kernel unchanged at 0.1.5-rc.2; no new permissions; the health check stays read-only and local.
