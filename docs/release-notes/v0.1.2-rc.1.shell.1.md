# dsh-desktop v0.1.2-rc.1.shell.1

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-rc.1`（未变，壳修订 +1）。

## 本次更新

- **首次成功路径**：应用内「扩展入口 / 扩展设置」更名为更直白的「桌面工具 / 桌面设置」。主界面新增可关闭、非模态的四步引导：运行环境就绪 → 选择工作区 → 配置模型 → 完成第一条任务；首次任务成功后自动结束，已有成功会话的升级用户不会被重新打扰。
- **一键运行体检**：桌面设置首屏可检查随包 Node/Harness/桌面组件、两个数据目录与磁盘、Harness loopback、Profile、插件市场、安全模式和内核版本。每项显示「正常 / 警告 / 失败」与对应动作。
- **插件仍然可选**：首次引导明确说明无需先装插件；社区插件和插件市场仍由用户主动安装，不进入安装包，也不会静默恢复。
- **隐私与安全边界**：体检默认仅在本地只读执行；代理、registry、更新源连通性只有勾选后才联网。结果不返回路径、URL、日志、代理地址或捕获错误，不上传，也不自动修复用户文件。

## 验证

- Node 22 类型检查、单测与覆盖率、站点检查、Electron stub E2E、真实打包 Harness UI、Safe Mode、插件市场和跨版本升级门禁通过。
- GitHub 三平台发布资产、来源证明与 SHA-256 完整；GitCode 六个用户资产镜像和官网版本数据已复核。

## English Summary

- Renamed the hidden “Extensions” entry to **Desktop tools / Desktop settings** and added a dismissible, non-modal runtime → workspace → model → first-task guide that retires itself after the first successful task.
- Added a one-click health check for bundled files and versions, both data roots and disk space, Harness loopback, profile, plugins, market, Safe Mode, and kernel state, with clear OK / warning / failed actions.
- Local checks are read-only and offline by default. Proxy, registry, and update-source probes require explicit opt-in; results are sanitized, never uploaded, and never repair user files automatically.
- The plugin market remains optional and manually installed; no community plugin is bundled or restored silently.
