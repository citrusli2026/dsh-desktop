# dsh-desktop v0.1.2-rc.1.shell.3

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-rc.1`（未变，壳修订 +3）。

## 本次更新

- **错误页插件恢复**：启动因坏插件失败时，恢复中心现在按包列出可疑插件，并提供「升级」「禁用」与「全部升级并重启」。升级走现有 `dsh plugin add` 通道拉取 npm 最新版；禁用只从启动 bundle 列表移除，文件保留，可随时在「设置 → 插件」重新启用。官方内置包被明确拒绝，防止误升级破坏与内核的版本锁定。
- **一键升级解决内核断崖**：内核升级导致插件 API 不兼容（如 0.1.2-rc.1 移除 `installSettingsSection`）时，用户无需再手动翻日志排查——错误页直接给出可操作的修复动作，成功后自动重启。
- **LAN 配对二维码回归保护**：新增 E2E 覆盖二维码窗口全链路（代理启动、健康检查、配对码铸造、二维码渲染），验证地址为私网 IP、6 位单次配对码。
- **边界说明**：插件升级需要网络与 npm registry；禁用与升级只触碰用户 profile 的 bundle 清单，不删除插件文件；官方包不在可操作范围内。

## English Summary

- Error-page plugin recovery: when startup fails on incompatible community plugins, the recovery center lists each suspect with Update, Disable, and Update-all-and-restart actions; updates pull the latest npm version via the existing `dsh plugin add` path, disable only removes the boot bundle entry (files kept, reversible from Settings → Plugins), and official bundles are always refused.
- New E2E coverage: a simulated plugin crash renders the recovery rows, disabling boots the app again with the manifest verified on disk; the LAN pairing QR window is covered end to end (private address, single-use 6-digit code, QR rendered).
- Bundled kernel unchanged at `@deepseek-ai/dsh` 0.1.2-rc.1 (shell revision +3).
