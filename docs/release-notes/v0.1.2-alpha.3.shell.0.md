# dsh-desktop v0.1.2-alpha.3.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-alpha.3`（内核升级，壳修订归零）。

## 本次更新

- 扩展入口重排：浮层按「连接 → 恢复 → 信息」组织，连接移动设备成为首要操作；安全模式、重启和关于均补充用途说明，运行状态保持可见但不再抢占主操作。
- 扩展设置优化：桌面习惯、账户与插件、恢复和高级工具分区展示；修复局域网、快捷键、插件市场与安全模式在中英文窄卡片中的错位、断字和按钮越界，并为窄窗口提供单栏布局。
- 内核与闭包：升级并锁定 `@deepseek-ai/dsh` `0.1.2-alpha.3`，同步完整 dsh 依赖白名单与锁文件；社区插件仍不进入安装包，只能由用户主动安装。
- 产品截图：更新扩展浮层与设置页的中英文、明暗主题真实应用截图，保证官网展示与本次桌面版本一致。

## 验证

- Harness 闭包重新物化并通过非可选 peer 依赖审计；`pnpm run verify` 通过类型检查、运行时边界、184 项测试（行覆盖率 92.34%、分支 83.43%、函数 87.40%）、官网/API 检查和构建。
- 本地未压缩应用完成中英文、明暗主题的真实 Electron 截图复核；三平台安装包、资产证明、GitCode 镜像和官网 release data 由完整发布流程继续核验。

## English Summary

- Upgraded and pinned the bundled `@deepseek-ai/dsh` kernel to `0.1.2-alpha.3`, regenerated the dependency lock, and re-audited the packaged Harness closure.
- Reorganized the floating desktop panel into Connect, Recovery, and Information groups, with mobile pairing promoted as the primary action and concise descriptions added to every operation.
- Reworked Extensions settings into clear desktop-habits, account-and-plugins, recovery, and advanced sections; fixed bilingual wrapping, alignment, and overflow issues and added a single-column narrow layout.
- Refreshed the real-app website screenshots for both locales and themes; community plugins remain opt-in and are never bundled or silently restored.
