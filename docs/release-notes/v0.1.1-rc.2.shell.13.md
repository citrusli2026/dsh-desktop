# dsh-desktop v0.1.1-rc.2.shell.13

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.1-rc.2（内核不变，壳修订 +13）。

## 本次更新

- **社区插件全部按需安装**：安装包不再包含 dsh-market、Better Sidebar、任务看板或其他社区插件，首次启动也不会自动播种。用户先在 Harness「设置 → 扩展设置 → 插件市场」手动安装 dsh-market，再按需安装其他社区插件和主题。
- **修正测试配置误入发布包的问题**：移除 curated 首启播种代码和随包社区依赖，保留已有 profile 不变；测试阶段已经安装到用户目录的插件仍由用户在「设置 → 插件」中自行卸载。
- **官网与文档同步**：插件市场页面、FAQ、架构说明和决策记录均明确“社区插件由用户主动安装”，避免把社区插件误解为官方内置能力。
- **边界说明**：dsh-desktop 仍只自带官方 Harness bundle 与壳自有 `dsh-desktop-controls`；社区插件安装、更新、构建脚本授权都由用户明确触发。

## 验证

- 本地 `pnpm run verify` 全绿：类型检查、单测与覆盖率门禁、双语官网检查、下载 API 检查、Harness 闭包 bootstrap 和主进程/预加载构建均通过；闭包中三个测试插件均不存在。
- GitHub Release 继续执行三平台打包、attestation、packaged smoke 与安装态验证；GitCode 镜像和官网 release data 在发布完成后按 runbook 同步。

## English Summary

- **Community plugins are opt-in:** installers no longer contain dsh-market, Better Sidebar, Task Board, or any other community plugin, and first launch performs no automatic seeding. Users manually install dsh-market from Harness Settings → Extensions → Plugin market, then install other plugins and themes as needed.
- **Test setup removed from the release path:** curated first-run seeding and the vendored community dependencies are gone; existing profiles remain untouched and any test-installed plugins stay user-owned.
- **Website and docs corrected:** the plugin-market page, FAQ, architecture notes, and decision record now state clearly that community plugins are installed by the user.
- **Boundary:** the desktop bundle contains only the official Harness bundles and shell-owned `dsh-desktop-controls`; plugin installation, updates, and build-script approval are explicit user actions.
