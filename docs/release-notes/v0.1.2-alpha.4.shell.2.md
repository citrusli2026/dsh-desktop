# dsh-desktop v0.1.2-alpha.4.shell.2

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-alpha.4`。

## 本次更新

- 插件安装反馈：手动安装 dsh-market 现在明确展示准备、下载、验证与重启阶段；完成后显示 profile 中的实际安装版本，Harness 重载后仍保留本次结果。
- 可行动的失败原因：区分网络、代理、超时、数据目录、安装脚本和随包工具故障；dsh/pnpm 的 stdout 与 stderr 会合并、限长并脱敏，可在设置页查看/复制，也会写入本地诊断报告。失败不会被误标为已安装，修复环境后可直接重试。
- 真实环境回归：新增无网络/无缓存的确定性安装失败 E2E，以及中文、暗色、960×640、中文与空格路径下的真实 dshmarket 安装、重启、版本与布局检查。
- 跨版本升级：Release 三平台在发布前下载并校验上一公开版本；macOS/Linux 完成原位覆盖，Windows 完成旧程序静默卸载后向同一位置安装新版。三者都必须证明同一用户 Profile 中的设置、壳偏好、标记和插件文件逐项保持不变，Safe Mode 仍能隔离坏插件并启动。
- 发布门禁隔离：常规 Electron E2E 在没有 `dist` 的干净 CI 环境中会在 fixture 启动前跳过专用市场用例；离线和真实安装仍由各自的打包态门禁执行，避免本地旧产物掩盖配置错误。
- 内核与边界：锁定 `@deepseek-ai/dsh` `0.1.2-alpha.4`；随包与 CI pnpm 升级至修复 GHSA-vx52-2968-3vc6 的 `11.11.0`。社区插件仍不进入安装包，不会首次启动静默安装，真实市场安装仍由用户确认。

## 验证

- 类型检查、运行时边界、193 项单元测试与覆盖率、官网/API 门禁和构建均纳入 `pnpm run verify`；alpha.4 闭包通过 frozen install、供应链 release-age 白名单和非可选 peer 审计。
- 本地完整门禁覆盖无 `dist` 的开发态 Electron E2E、打包产物普通/真实 UI/Safe Mode smoke、packaged E2E、离线市场安装；真实市场安装作为发布前网络门禁单独通过。
- macOS 本地从已发布 alpha.3 dmg 升级到本版本 dmg，并校验 7 个用户文件在新版本启动前后保持一致；Windows 与 Linux 在各自 Release runner 执行同一数据保留契约。

## English Summary

- Manual dsh-market installation now reports prepare, download, verification, and restart phases, preserves the result across the Harness reload, and shows the actual installed profile version.
- Network, proxy, timeout, profile, install-script, and bundled-tool failures are distinguished. Bounded stdout/stderr detail is sanitized before it can be viewed, copied, or written to local diagnostics; failed attempts remain retryable and are never shown as installed.
- New packaged E2E covers deterministic offline failure and a real market install under Chinese/dark/minimum-width and Unicode-path conditions.
- Every release platform verifies the previous installer checksum and preserves user-owned Harness and shell state across an upgrade. macOS/Linux use in-place replacement; Windows silently removes the old application binaries before installing the new version to the same target because electron-builder's assisted NSIS silent-overwrite path can stall. Clean CI runs skip dedicated market specs before fixture setup, while their packaged gates still run separately. Bundled/CI pnpm is patched to `11.11.0`.
