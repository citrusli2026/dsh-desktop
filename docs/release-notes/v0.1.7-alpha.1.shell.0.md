# dsh-desktop v0.1.7-alpha.1.shell.0

DeepSeek Harness 社区桌面版 · 内核升级并锁定官方 `@deepseek-ai/dsh` `0.1.7-alpha.1`（壳修订归零）。

## 本次更新

- **内核升级**：随官方 `@deepseek-ai/dsh` `0.1.7-alpha.1`（上一内置内核 0.1.6-alpha.2）。上游变更内容见 [官方发布页](https://github.com/deepseek-ai/deepseek-harness/releases)。
- **依赖闭包同步**：重新生成 lockfile，同步 supply-chain release-age 豁免清单；官方 npm 安全审计零已知漏洞。
- **依赖闭包同步**：新内核 peer 缺口 `dsh-client-store`、`dsh-deepseek-account` 已加入闭包清单（audit 门指认）；12 个未随新内核发版的 dsh-* 包按解析版本保留，无版本倾斜。上游 0.1.7-alpha.1 内部曾引用未发布的 `dsh-terminal@0.1.7-alpha.2`，npmmirror 稍后补齐，巡检按 §51 轮询后确认可解析。
- **内核行为变化（对用户可见）**：0.1.7 起内核对损坏的社区插件改为「隔离并继续启动」，插件不再拖垮整个 Harness；壳的启动冒烟已按新契约更新。
- **验证**：296 项单测、双树审计零已知漏洞、dev E2E 16/16、打包冒烟（真实渲染 + 安全模式故障注入 + 闭包校验）、离线/真实市场 E2E（含真实 dshmarket 安装与版本核对）、垃圾桶 UI E2E、LAN 扫码全部通过。
- **边界说明**：桌面壳无功能变更；社区插件仍不进入安装包。若插件与新内核不兼容，启动失败时错误页提供一键「升级 / 禁用」恢复。

## 验证

- Release 门禁：verify（296 项单测 + E2E）、macOS/Windows/Linux 构建、packaged smoke、attestation、跨版本升级数据保留、离线/真实市场与 LAN 扫码。

## English Summary

- Kernel bump: bundled `@deepseek-ai/dsh` locked to `0.1.7-alpha.1` (previous 0.1.6-alpha.2); shell revision reset to 0. See the [official upstream release notes](https://github.com/deepseek-ai/deepseek-harness/releases) for kernel changes.
- New-kernel peer gaps (dsh-client-store, dsh-deepseek-account) joined the closure; 12 sub-packages without a 0.1.7-alpha.1 release stay at their resolved versions. Kernel 0.1.7 now isolates a broken community plugin and keeps booting — the shell startup smoke follows that contract. Zero known vulnerabilities in both npm trees.
- Desktop shell unchanged. If a community plugin is incompatible with the new kernel, the error page offers one-click Update / Disable recovery.
