# dsh-desktop v0.1.7-alpha.2.shell.0

DeepSeek Harness 社区桌面版 · 内核升级并锁定官方 `@deepseek-ai/dsh` `0.1.7-alpha.2`（壳修订归零）。

## 本次更新

- **内核升级**：随官方 `@deepseek-ai/dsh` `0.1.7-alpha.2`（上一内置内核 0.1.6-alpha.2）。上游变更内容见 [官方发布页](https://github.com/deepseek-ai/deepseek-harness/releases)。
- **依赖闭包同步**：重新生成 lockfile，同步 supply-chain release-age 豁免清单（12 个未随新内核发版的 dsh-* 包按解析版本保留，无版本倾斜）；官方 npm 安全审计零已知漏洞。
- **依赖闭包同步**：新内核 peer 缺口 `dsh-client-store`、`dsh-deepseek-account` 已加入闭包清单（audit 门指认，与 0.1.7-alpha.1 预演一致）。
- **内核行为变化（对用户可见）**：0.1.7 起内核对损坏的社区插件改为「隔离并继续启动」，插件不再拖垮整个 Harness；设置文件无损迁移（旧文件逐字节归档为 `.imported`）；设置入口移至左下角账号弹层。壳的启动冒烟、升级数据保留断言与设置导航 E2E 均已按新契约更新（随 v0.1.6-alpha.2.shell.4 入库，本轮首次随内核发版验证）。
- **边界说明**：桌面壳无功能变更；社区插件仍不进入安装包。若插件与新内核不兼容，启动失败时错误页提供一键「升级 / 禁用」恢复。

## 验证

- 本地门禁：verify 全绿（typecheck、297 项单测 + 覆盖率、站点检查、构建）、LAN 扫码 E2E 2/2。
- Release 门禁（CI）：macOS/Windows/Linux 构建、packaged smoke、attestation、跨版本升级数据保留（含 0.1.7 设置迁移两态断言）、离线/真实市场 E2E。

## English Summary

- Kernel bump: bundled `@deepseek-ai/dsh` locked to `0.1.7-alpha.2` (previous 0.1.6-alpha.2); shell revision reset to 0. See the [official upstream release notes](https://github.com/deepseek-ai/deepseek-harness/releases) for kernel changes.
- Kernel 0.1.7 behavior changes: a broken community plugin is now isolated instead of crashing the boot; settings migrate losslessly (old file archived byte-exact as `.imported`); the settings entry moved into the account popup. The shell's startup smoke, upgrade-retention assertions and settings-navigation E2E follow the new contract (landed with v0.1.6-alpha.2.shell.4, first exercised on a kernel release here).
- New-kernel peer gaps (dsh-client-store, dsh-deepseek-account) joined the closure; 12 sub-packages without a 0.1.7-alpha.2 release stay at their resolved versions. Zero known vulnerabilities in both npm trees.
- Desktop shell unchanged. If a community plugin is incompatible with the new kernel, the error page offers one-click Update / Disable recovery.
