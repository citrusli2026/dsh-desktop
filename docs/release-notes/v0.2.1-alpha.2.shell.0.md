# dsh-desktop v0.2.1-alpha.2.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-alpha.2`（内核升级，壳修订归零）。

## 本次更新

- **飞书消息连接**：从原生「扩展 / Desktop tools」菜单打开独立二维码配置窗口，完成回调后由受监督的 cc-connect Sidecar 将飞书消息接入 DSH；设置页支持启动、停止、重连和 Safe Mode 生命周期。
- **一键 CLI 与 skills**：新增 `pnpm run feishu:setup`，调用官方 Lark CLI 完成用户 OAuth，并可安装官方 `lark-*` skills；用户 CLI 身份与 cc-connect 机器人身份明确分离。
- **运行时与可靠性**：升级内置 DSH 到 `0.2.1-alpha.2`，同步 32 个 peer pin，并按新内核重建登录自动打开补丁；新增多运行时管理面板及更严格的运行时路径校验。
- **安全边界**：二维码配置使用临时目录，Secret 只进入受保护凭证存储或权限为 `0600` 的文件，不写入日志、仓库或普通设置文件。

## 验证

- `pnpm run verify` 通过：341 项测试、typecheck、runtime check、覆盖率（88.84% 行 / 80.03% 分支 / 84.29% 函数）、site check 和 build；LAN pairing 2/2、market offline 1/1、market real 2/2、packaged smoke 通过。
- 真实飞书链路已验证：websocket 入站 → cc-connect → DSH ACP → 飞书回包；发布流水线将继续完成三平台安装包、GitCode 镜像和官网 release 数据校验。

## English Summary

- Upgrades the bundled `@deepseek-ai/dsh` runtime to `0.2.1-alpha.2`, synchronizes 32 kernel peer pins, and rebuilds the sign-in auto-open patch for the new package.
- Adds a native Feishu setup flow with a QR window, supervised cc-connect sidecar, lifecycle controls, and a one-command official Lark CLI skill installer.
- Adds the multi-runtime dashboard and tightens runtime version/path validation.
- Temporary setup files and credentials stay isolated and permission-protected; secrets are never written to logs or ordinary settings.
- Verification passed: 341 tests, typecheck, coverage, site checks, build, LAN pairing 2/2, market offline 1/1, market real 2/2, packaged smoke, and a live Feishu message round trip.
