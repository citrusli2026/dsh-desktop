# dsh-desktop v0.1.1-rc.2.shell.15

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.1-rc.2（未变，壳修订 +15）。

## 本次更新

- 启动状态反馈：明确展示“正在启动运行时 / 等待 Harness 就绪 / 自动重试 / 运行中 / 恢复暂停”，并在自动重试时显示尝试次数和等待时间。
- 桌面入口同步：托盘、设置页、悬浮扩展面板、加载页和诊断报告使用同一套生命周期状态；重启期间不会继续显示旧的“运行中”。
- 官网实拍展示：官网新增中英文真实应用截图轮播，支持明暗主题对应截图、自动滚动、悬停/聚焦暂停，并补充 shell.15 功能说明。
- 边界说明：本版本仍是可靠的 Electron 壳加上开箱即用支持；社区插件不进入安装包，全部由用户手动安装，不新增 Agent 工作台。

## 验证

- `pnpm run verify` 通过：类型检查、运行时边界、184 项测试与覆盖率、官网/API 门禁、构建均通过；开发态 Electron E2E 为 12 项通过、1 项打包专用用例按条件跳过。
- 官网视觉已检查中文桌面版、中文 390px 窄屏、英文版和明暗主题；轮播 6 秒自动切换且无横向溢出。打包 smoke、GitHub Release、GitCode 镜像和线上 release data 在发布流程中复核。

## English Summary

- Startup feedback now distinguishes launching the bundled runtime, waiting for Harness, automatic retry, running, and recovery paused, including retry count and delay.
- Tray, settings, floating desktop controls, loading pages, and diagnostics share the same lifecycle state so a restart does not leave stale “running” text behind.
- The bilingual website now includes real application screenshots with light/dark matching, an auto-advancing carousel, and a focused shell.15 update summary.
- The release keeps the dependable Electron shell boundary: community plugins are never bundled or silently installed, and no Agent workbench is added.
