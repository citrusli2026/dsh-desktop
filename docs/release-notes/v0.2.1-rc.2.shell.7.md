# dsh-desktop v0.2.1-rc.2.shell.7

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-rc.2（未变，壳修订 6 → 7）。

## 本次更新

- **小鲸鱼桌宠成为可选的内置扩展**：安装包自带**未经修改**的社区插件 `dsh-whale-widget` 0.4.2。
  插件不需要声明伴随窗口、也不需要提供 pet 路由——壳按已知包版本提供描述，并自己提供一个适配页加载
  插件原有的 `/dsh-whale/widget.js`。打开「桌面设置 → 扩展 → 小鲸鱼桌宠」勾选并点「立即重启」即可：
  右下角显示 DeepSeek 余额与今日已用，主窗口最小化后小鲸鱼留在桌面，点右上角 `−` 或按 Esc 收起。
- **默认关闭、可随时关闭**：`whaleWidgetEnabled` 缺省为 false；关闭后壳不挂载插件，并移除自己创建的
  profile 链接，插件列表、桌面工具面板和伴窗都不再出现该插件。Safe Mode 下一律不挂载。
  插件将来若自己声明 `dsh.companion`，以插件声明为准，壳的适配层自动让位。
- **署名与上游入口**：设置页写明原作者 MeteorNOX，并提供「打开原作者项目」按钮；插件副本固定随壳分发，
  不跟随 npm 自动更新。代码为 MIT，美术/音频素材按上游 `PROVENANCE.md` 原样分发（见
  `third_party/dsh-whale-widget/VENDORED.md`）。
- **边界不变**：壳仍不读 Harness DOM、不调用 `executeJavaScript`、不提供审批桥；伴窗内的审批动作只会
  把用户带回主窗口确认，Safe Mode 与第三方插件隔离承诺保持。
- **安装包体积**：新增约 7 MB 的内置插件资源（角色图、音效、前端脚本）。

## English Summary

- **The whale companion is now an optional built-in extension**: the installer ships the community
  `dsh-whale-widget` (upstream 0.4.2 plus the companion-window integration patch proposed upstream).
  Enable it in “Desktop settings → Extensions → Whale companion”, click “Restart now”, and the whale shows
  DeepSeek balance and today's spend; minimizing the main window keeps it on the desktop and `−` restores.
- **Off by default, removable**: `whaleWidgetEnabled` defaults to false; disabling unmounts the plugin and
  removes the shell-owned profile links, so the plugin list, panel and companion disappear. Safe Mode never
  mounts it.
- **Attribution**: the settings row names MeteorNOX and links the upstream project; the vendored copy never
  auto-updates from npm. Code is MIT; artwork/audio stay under upstream `PROVENANCE.md`
  (`third_party/dsh-whale-widget/VENDORED.md`).
- **Boundary unchanged**: no DOM access, no `executeJavaScript`, no approval bridge; companion approvals
  hand off to the main window.
- **Verification**: full local verify, a new packaged end-to-end for the toggle → restart → whale → pet path,
  the default-off and Safe Mode cases, plus the existing companion and external-plugin suites.
