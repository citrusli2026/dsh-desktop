# dsh-desktop v0.1.6-alpha.2.shell.4

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.6-alpha.2（未变，壳修订 +4）。

本轮为 **局域网入口虚拟网卡支持**（社区 #63）与测试健壮性轮。

## 本次更新

- **局域网入口支持 VPN 虚拟网卡（Tailscale / ZeroTier 等）**：CGNAT 段 `100.64.0.0/10` 现在被视为合法局域网地址——此前即使通过 `DSH_LAN_IP` 显式指定也会被拒绝。自动探测顺序保持物理网卡（Wi-Fi/以太网）优先，没有物理网卡可达时自动使用 Tailscale/ZeroTier 等 VPN 虚拟网卡；同一虚拟网内的手机扫码即可进入 Harness。
- **测试健壮性**：打包 E2E 的设置页导航适配多版内核 UI（含 0.1.7 的账号弹层入口），升级冒烟接受 0.1.7 的设置文件迁移契约（`settings.yaml` → `.imported` 逐字节归档），为下一版内核升级铺路。
- **内核与边界不变**：内置内核仍为 0.1.6-alpha.2；不新增权限、不改变数据目录边界。

## English Summary

- LAN mobile access now supports VPN virtual adapters (#63): CGNAT 100.64.0.0/10 addresses (Tailscale/ZeroTier) are accepted as private LAN IPs. Auto-discovery keeps physical NICs first and falls back to VPN adapters; a phone on the same virtual network can pair via the QR code. `DSH_LAN_IP` also accepts CGNAT addresses.
- Packaging E2E hardened across kernel UI versions; the upgrade smoke follows kernel 0.1.7's settings-file migration contract ahead of the next kernel bump. Bundled kernel unchanged at 0.1.6-alpha.2.
