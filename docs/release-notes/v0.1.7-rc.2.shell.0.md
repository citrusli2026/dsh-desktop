# dsh-desktop v0.1.7-rc.2.shell.0

DeepSeek Harness 社区桌面版 · 内核升级并锁定官方 `@deepseek-ai/dsh` `0.1.7-rc.2`（壳修订归零），同时修复 UOS/Deepin 桌面适配问题（#73）。

## 本次更新

- **内核升级**：随官方 `@deepseek-ai/dsh` `0.1.7-rc.2`（上一内置内核 0.1.7-rc.1）。上游变更见 [官方发布页](https://github.com/deepseek-ai/deepseek-harness/releases)。
- **UOS/Deepin 桌面适配（#73）**：
  - 主窗口在 Linux 上携带应用图标（`_NET_WM_ICON`），任务栏/启动器不再因图标主题缺 hicolor 回退链而显示系统默认图标；
  - Linux 恢复**完整原生标题栏**：0.1.7 新 UI 的右上角操作区与原生窗口控件（关闭/最大化/最小化）完全重叠，改用系统标题栏后不再有点击冲突，也更符合 UOS/Deepin 桌面习惯。macOS/Windows 的隐藏标题栏样式不变。
- **登录授权自动打开补丁随 rc.2 重建**：账号设置中 DeepSeek 登录授权页自动打开的体验补丁已按 rc.2 重建（此前仅适配 rc.1）。
- **依赖闭包同步**：新 peer `dsh-llm-deepseek` 入清单；12 个未随 rc.2 发版的子包按解析版本保留；双树 npm 审计零已知漏洞。
- **内核与边界不变**：不新增权限、不改变插件安装与数据目录边界；体检保持只读、不上传、不自动修复。

## English Summary

- Kernel bump to official `@deepseek-ai/dsh` 0.1.7-rc.2 (previous 0.1.6-alpha.2 line via rc.1).
- UOS/Deepin desktop adaptation (#73): the Linux main window now carries the app icon (`_NET_WM_ICON`) so taskbars stop showing a default icon, and Linux restores the full native title bar — the 0.1.7 web UI's top-right actions no longer collide with native window controls. macOS/Windows keep their hidden-title-bar styles.
- The DeepSeek login auto-open patch was rebuilt against rc.2. Closure peers synced; zero known vulnerabilities.
