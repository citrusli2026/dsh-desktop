# dsh-desktop v0.1.6-alpha.2.shell.1

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.6-alpha.2（未变，壳修订 +1）。

本轮为**垃圾桶完善轮**：设置页的垃圾桶区块按统一设计体系重写，补齐不可逆操作确认与会话页签的真实语义，并修复两处功能缺陷。

## 本次更新

- **设计体系统一**：垃圾桶区块改用与「桌面设置」相同的设计组件——分组卡片、行排版、统一按钮与徽标、真页签（tablist）；条目显示类型徽标、删除时间与「N 天后自动清除」倒计时；空状态为引导卡片，不再是裸 HTML。
- **不可逆操作加确认**：「彻底删除」改为行内两步确认（确认/取消），「清除已过期」同样确认；会话页签的删除按钮改名为「删除（入桶）」——它本来就可还原，旧文案「彻底删除」是误导。
- **会话页签真实语义**：分组展示「已归档 / 未归档」，并说明模型：删除会话先入垃圾桶（30 天内可还原），归档仅在列表中隐藏。
- **修复：归档会话判定失效**：内核工作区注册表把归档列表嵌在 `global` 字段下，壳只读顶层导致归档会话永远显示为未归档；现兼容两种结构，取消归档的写回也保持内核的 unit 头格式。
- **修复：内核残留入桶**：「恢复内置内核」后，被切走的 overlay 内核目录现在移入垃圾桶（30 天还原窗口），不再永久占用磁盘；移动失败时保持原样，绝不影响恢复本身。
- **测试网**：新增打包 E2E（种子条目还原 → 启动期过期清理断言 → 两步确认清除 → 会话入桶全链贯穿 UI）与契约测试断言（设计体系 class、确认交互、页签语义），让垃圾桶的风格漂移未来能被 CI 拦住。

## English Summary

- The trash settings section is rewritten on the shared settings design system: group cards, real tabs, kind badges, retention countdown, guided empty states.
- Irreversible actions (delete-forever, clear-expired) now require an inline two-step confirm; the sessions tab tells the truth — delete moves a session to the trash (recoverable for 30 days) instead of claiming to destroy it.
- Fixed archived-session detection (the kernel nests the archived list under `global`; the shell now reads both shapes and preserves the unit header on write) and kernel overlays now retire to the trash when you restore the bundled kernel.
- New packaged E2E drives the full UI journey (restore, boot-time expiry sweep, confirmed purge, session-to-trash) plus contract assertions guarding the design system.
