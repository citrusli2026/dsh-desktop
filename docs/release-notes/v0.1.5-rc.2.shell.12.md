# dsh-desktop v0.1.5-rc.2.shell.12

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.5-rc.2（未变，壳修订 +5）。

本轮为 **Windows 修复闭环与门禁降本**轮：损坏检出后的"最后一步"补齐，CI 更快更省。

## 本次更新

- **修复闭环**：运行体检检出安装损坏时，结果直接附「获取重装包」按钮——按平台与线路（国内 GitCode / 国际 GitHub）一键直达**与你当前版本完全一致**的安装包下载，并附三步重装指引（退出应用 → 覆盖安装 → 重新体检）；另一条线路作为备用链接并列展示。「导出诊断报告」同步附上直链，贴到 issue 即可定位。
- **升级矩阵更严也更快**：残留矩阵三个场景改为共享一次基线安装（目录复制代替重复安装），Windows 构建时间明显回落；当检测到构建环境开启 Defender 实时保护时，自动追加一轮"杀软干扰下损坏→升级"重复验证（S4）。
- **CI 提速**：E2E 门禁改回直接运行 Playwright——1.63 已无 worker teardown 挂起（观察轮，护卫脚本保留可随时回退）。
- **内核与边界不变**：内置内核仍为 0.1.5-rc.2；不新增权限、不改变插件安装与数据目录边界；体检保持只读、不上传、不自动改写文件。

## 验证

- 282 项单测、dev E2E 16/16、LAN 配对 2/2、离线 + 真实市场安装通过、闭包 smoke（干净 + 篡改）、安全模式两阶段冒烟本地全绿。
- 三平台构建与残留矩阵（含 S4 条件轮）随发布流水线执行；双树 npm 审计零已知漏洞。

## English Summary

- Repair loop: when the health check detects a damaged install, the result now ships a "Get the installer" button that deep-links the exact-version installer for your platform (GitCode for mainland China, GitHub internationally) plus a three-step reinstall guide; the diagnostics export carries the same links.
- The NSIS residue matrix shares one baseline install (robocopy instead of repeated installs), cutting Windows build time; when Defender real-time protection is detected, an extra corrupted→upgraded repeat pass (S4) runs automatically.
- CI E2E gates run plain Playwright again (1.63 no longer hangs at teardown; the guarded-runner script is kept for a quick revert). Bundled kernel unchanged at 0.1.5-rc.2; no new permissions; the health check stays read-only and local.
