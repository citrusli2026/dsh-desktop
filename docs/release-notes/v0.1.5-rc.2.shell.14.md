# dsh-desktop v0.1.5-rc.2.shell.14

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.5-rc.2（未变，壳修订 +7（.12/.13 失败 tag 保留审计））。

本轮为 **Windows 修复闭环与门禁降本**轮：损坏检出后的"最后一步"补齐，CI 更快更省。

## 本次更新

- **修复闭环**：运行体检检出安装损坏时，结果直接附「获取重装包」按钮——按平台与线路（国内 GitCode / 国际 GitHub）一键直达**与你当前版本完全一致**的安装包下载，并附三步重装指引（退出应用 → 覆盖安装 → 重新体检）；另一条线路作为备用链接并列展示。「导出诊断报告」同步附上直链，贴到 issue 即可定位。
- **升级矩阵环境感知**：残留矩阵在运行时探测构建环境的 Defender 实时保护并记录到输出；仅当保护开启时追加一轮"杀软干扰下损坏→升级"重复验证（S4）。实现中确认 NSIS 卸载器内嵌安装目录（安装树不可克隆），维持逐场景真实安装的正确性优先策略。
- **内核与边界不变**：内置内核仍为 0.1.5-rc.2；不新增权限、不改变插件安装与数据目录边界；体检保持只读、不上传、不自动改写文件。

## 验证

- 282 项单测、dev E2E 16/16、LAN 配对 2/2、离线 + 真实市场安装通过、闭包 smoke（干净 + 篡改）、安全模式两阶段冒烟本地全绿。
- 三平台构建与残留矩阵（含 S4 条件轮）随发布流水线执行；双树 npm 审计零已知漏洞。

## English Summary

- Repair loop: when the health check detects a damaged install, the result now ships a "Get the installer" button that deep-links the exact-version installer for your platform (GitCode for mainland China, GitHub internationally) plus a three-step reinstall guide; the diagnostics export carries the same links.
- The NSIS residue matrix now records the build environment's Defender real-time-protection state and runs an extra corrupted→upgraded pass (S4) only when protection is on. (A baseline-sharing optimization was reverted: NSIS uninstallers embed their install directory, so install trees cannot be cloned for uninstaller-based tests.)
- CI keeps the guarded E2E runner: a worker-teardown hang reproduced once more on the Linux runner under Playwright 1.63, so the retirement is postponed (local macOS runs stay clean). Bundled kernel unchanged at 0.1.5-rc.2; no new permissions; the health check stays read-only and local.
