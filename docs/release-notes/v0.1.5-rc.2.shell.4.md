# dsh-desktop v0.1.5-rc.2.shell.4

Bundled kernel `@deepseek-ai/dsh` 0.1.5-rc.2 (unchanged; shell revision +4).

## Changes

- **Agent deletion interception now works for real**: the hook no longer exits on a stale local `hooks.json` lookup, and packaged builds now ship `resources/agent-trash-hook`.
- **User-controllable toggle**: Desktop settings exposes the deletion interception switch and restarts Harness so the hook patch is mounted or removed.
- **Safe command quoting and rollback**: hook commands quote paths with spaces/apostrophes, and a failed trash index write restores the file to its original path.
- **Startup recovery hardening**: supervisor spawn errors after readiness now enter the normal restart budget instead of silently stopping.
- **Trash index hardening and docs alignment**: unsafe index rows are dropped, and README/FAQ now match the actual trash scope (presets, sessions, agent-deleted files).

## Verification

- 265 unit tests pass; coverage 95.53% lines / 86.89% branches / 88.10% functions; typecheck, runtime boundary, site check, and main/preload build pass.
- New process-level tests spawn the real hook and verify move/block/rollback behavior; packaged smoke now asserts the `agent-trash-hook` resource on each platform.
- GitHub release assets, attestation, cross-version upgrade, and GitCode mirror checks run in the standard release pipeline.

## English Summary

- The agent deletion hook now executes for real, ships in packaged builds, quotes paths safely, and rolls back if the trash index cannot be written.
- Deletion interception is user-controllable from Desktop settings; toggling it restarts Harness so the hook patch is applied or removed.
- Supervisor spawn errors after readiness enter the normal restart budget instead of silently stopping.
- Trash index parsing rejects unsafe ids/paths, and public docs now match the actual trash scope.
