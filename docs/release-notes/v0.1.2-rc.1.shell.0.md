# dsh-desktop v0.1.2-rc.1.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-rc.1`（内核升级，壳修订归零）。

## 本次更新

- 正式候选内核：从 `0.1.2-alpha.4` 升级并锁定官方 `0.1.2-rc.1`，包含官方在会话加载、长会话内存与密集实时消息渲染方面的优化，以及新版连接恢复、模型配置和界面改进。
- 上游同步恢复：修复每日 dsh-watch 缺少 `dsh-mobile-shell` Web artifact 导致的假失败；后续失败 Issue 只链接真实运行和首个失败步骤，不再默认归因为依赖年龄或上游不兼容。
- 依赖安全下限：锁定 `fast-uri`、`qs` 与 `@xmldom/xmldom` 的安全版本并重新生成两套锁文件；根依赖与 Harness 生产闭包的官方 npm 安全审计均为零已知漏洞。
- 边界不变：社区插件仍不进入安装包、不静默安装；dsh-market 继续由用户主动确认安装，Safe Mode 和本地脱敏诊断不改写用户数据。

## 验证

- Node 22 + pnpm 11.11.0 下通过 frozen install、闭包部署、非可选 peer 审计、193 项单元测试、覆盖率、网站/API 检查、12 项开发态 Electron E2E、打包启动和真实 Harness UI。
- watcher 的 checkout → `package:web` → smoke 路径在固定 `dsh-mobile-shell v1.0.0` 上复现通过；真实 dsh-market 安装、离线错误闭环和坏插件 Safe Mode 隔离均通过。
- macOS 从上一公开版 DMG 覆盖至本版，启动前后 7 个 Harness/壳/插件用户文件逐项保持一致；Windows 与 Linux 由 Release runner 执行同一跨版本契约。GitHub、GitCode 和官网数据在发布流程中继续逐项核验。

## English Summary

- Upgraded and pinned the bundled kernel to official `@deepseek-ai/dsh` `0.1.2-rc.1`, including upstream long-session, connection recovery, model configuration, and UI improvements.
- Fixed the daily kernel watcher by packaging the pinned mobile-shell Web artifact before smoke validation, and removed speculative root-cause language from future failure issues.
- Raised vulnerable transitive dependencies to explicit security floors; both the root tree and production Harness closure pass the official npm advisory audit with no known vulnerabilities.
- Local gates cover 193 unit tests, Electron E2E, real Harness rendering, real/offline dsh-market paths, Safe Mode recovery, and a macOS upgrade that preserves seven user-owned files. Community plugins remain explicit opt-in installs.
