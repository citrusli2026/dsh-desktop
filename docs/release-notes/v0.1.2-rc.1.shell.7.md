# dsh-desktop v0.1.2-rc.1.shell.7

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.1.2-rc.1`（未变，壳修订 +7）。

## 本次更新

- **桌面垃圾桶**：删除的会话、预设和插件都先进垃圾桶，不再一去不返。在 Harness「设置 → 垃圾桶」中查看、按原位置还原（同名冲突自动落副本）、或彻底清除；保留 30 天，过期自动清理。
- **Agent 删除有兜底**：Agent 执行的 `rm` 类删除命令会被桌面版拦截，目标先移入垃圾桶再放行；解析不了或越出工作区、触及 `node_modules`/`.git` 的可疑删除直接拦截并说明原因。可在「设置 → 桌面设置」关闭该开关。
- **插件失败自动隔离**：插件导致启动失败时，桌面版自动把问题插件移出启动列表并重启，应用先跑起来；被隔离的插件在恢复横幅中持续可见，升级即自动重新启用。
- **边界说明**：垃圾桶只覆盖桌面版自有资源与被拦截的 Agent 删除；壳外手动删除、系统其它操作不在覆盖范围。隔离与入桶都不删除原始文件，随时可逆。

## English Summary

- Desktop trash: deleted sessions, presets, and plugins stay recoverable from Settings → Trash with a 30-day retention window; restore falls back to numbered copies so newer data is never overwritten.
- Agent deletion interception: rm-style commands from the agent move targets into the trash before proceeding; ambiguous or out-of-scope deletions are blocked with an explanation (toggle in Desktop settings).
- Plugin crashes now auto-quarantine the suspect from the boot list and restart, so the app comes back up; quarantined plugins stay visible in the recovery banner until updated.
