# dsh-desktop v0.1.6-alpha.2.shell.2

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.6-alpha.2（未变，壳修订 +2）。

本轮为 **Windows 发布验证强化轮**：把 #56/#39 两类"用户机上文件丢失/损坏"问题挡在发布之前。

## 本次更新

- **Windows 安装器内容门禁（新增发布 gate）**:每个 Windows 安装器在发布前都会被解包核验——内置 `node.exe`、sharp 原生链(`.node` + libvips DLL)、闭包完整性清单、mobile-shell、agent-trash-hook 九个关键文件必须存在,其中最高风险的两个二进制(node.exe、sharp `.node`、libvips DLL)还会对照闭包 SHA-256 清单逐一校验哈希。这把 #39(运行时损坏)与 #56(原生模块加载失败)两类问题的验证从"用户机上发现"提前到"发布流水线拦截"。
- **诊断经验沉淀**:#56 的排查方法(NSIS → 内层 app-64.7z → 逐文件核对哈希)已固化为 `scripts/verify-windows-installer.mjs`,本地也可运行(`node scripts/verify-windows-installer.mjs <安装器或 dist 目录>`),配合 7-Zip 即可复现发布级校验。
- **内核与边界不变**:内置内核仍为 0.1.6-alpha.2;不新增权限、不改变插件安装与数据目录边界。

## 验证

- 288 项单测;dev E2E 16/16;三打包冒烟(真实 Harness UI 渲染 + 安全模式故障注入);垃圾桶 UI 打包 E2E;离线 + 真实市场 E2E;LAN 扫码 2/2;双树 npm 审计零已知漏洞。
- 新门禁在 v0.1.6-alpha.2.shell.1 真实安装器上回放验证通过(9 关键文件 + 3 哈希);发布流水线 Windows job 首次接入该 gate。
- 8 文件发布契约 + attestation + 三平台构建随发布流水线执行。

## English Summary

- New release gate: every Windows installer is unpacked and verified before publish — bundled node.exe, the sharp native chain (.node + libvips DLLs), the closure integrity manifest, mobile-shell, and agent-trash-hook must be present, with the highest-risk binaries hashed against the packaged closure manifest. Moves #39/#56-class verification from "discovered on user machines" to "blocked in the release pipeline".
- The verification method is packaged as scripts/verify-windows-installer.mjs (runnable locally with 7-Zip). Bundled kernel unchanged at 0.1.6-alpha.2.
