# dsh-desktop v0.2.1-alpha.1.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-alpha.1（内核升级，壳修订归 0）。

## 本次更新

- **内核升级**：从 0.2.0-rc.2 升级到 0.2.1-alpha.1，同步桌面壳的插件兼容版本与随包依赖。
- **局域网配对**：记住用户选择的网络地址；多网卡环境中先核对二维码所指向的地址，避免二维码指向不可用网卡。
- **桌面垃圾桶**：卡片、操作按钮和页签与设置页视觉风格一致；中文界面按中文格式显示日期，运行中的会话被拒绝删除时显示正确原因。
- **数据边界**：不新增权限，不改变用户数据目录或垃圾桶的 30 天保留规则。

## 验证

- 候选版已通过 `pnpm run verify`（303 项单测）、`dist:dir` 和打包版垃圾桶 E2E；此前同一内核候选的局域网、市场和打包冒烟门禁也已通过。
- **尚未发布**：双树安全审计均被 `http-cache-semantics@4.2.0` 的高危公告拦截，公告尚无修复版本。安全门禁恢复全绿后须重跑完整发版验证，再更新本节并发布。
