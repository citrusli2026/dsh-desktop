# dsh-desktop v0.1.5-rc.2.shell.5

Bundled kernel `@deepseek-ai/dsh` 0.1.5-rc.2 (unchanged; shell revision +5).

## Changes

- **The desktop tools overlay now carries every desktop tool**: a new Maintenance group adds check-for-updates, open-logs, and export-diagnostics alongside pairing, Safe Mode, restart, and About, so all shell tools are reachable from the floating panel without the menu bar or tray.
- **The mobile pairing (QR) window hides its menu bar on Windows/Linux** like the home page, by reusing the shell's hidden-title-bar chrome instead of rendering a native menu bar.
- **Safer kernel bumps**: `version.mjs bump dsh` now auto-syncs the `@deepseek-ai/dsh-*` peer pins, so automated bump PRs can no longer ship stale plugin-facing ranges (the #31 failure class).
- **Kernel-compat advisories**: the health check warns when an installed bundle's declared kernel range excludes the running kernel (npm prerelease semantics included), turning the silent #33 failure mode into a visible, actionable warning.
- **Safe Mode survives a crashed profile**: crash-time plugin suspects are persisted and the safe-mode overlay can still be written when the profile manifest was never composed (the #35/#40 race), and crash smokes now dump the harness log tail for diagnosability.
- **Runtime spawn failures are explained**: `spawn EFTYPE/ENOENT` pages and diagnostics now point to a full reinstall (the #39 damaged-node class).
- **Mirror daemon resilience**: the GitCode mirror launchd daemon resolves a Node binary itself (Homebrew/Volta/nvm fallbacks) instead of relying on the GUI login PATH.
