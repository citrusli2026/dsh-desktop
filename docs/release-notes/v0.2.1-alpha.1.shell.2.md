# dsh-desktop v0.2.1-alpha.1.shell.2

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-alpha.1（内核升级，壳修订归 2）。本版沿用 shell.0 的功能与安全修复，并完善 Windows 发布门禁在连续 NSIS 场景间清理残留进程的处理。

## 本次更新

- **内核升级**：从 0.2.0-rc.2 升级到 0.2.1-alpha.1，同步桌面壳的插件兼容版本与随包依赖。
- **局域网配对**：记住用户选择的网络地址；多网卡环境中先核对二维码所指向的地址，避免二维码指向不可用网卡。
- **桌面垃圾桶**：卡片、操作按钮和页签与设置页视觉风格一致；中文界面按中文格式显示日期，运行中的会话被拒绝删除时显示正确原因。
- **Windows 发布门禁**：NSIS 残留矩阵在场景之间清理 dsh-desktop 进程族，避免后续静默安装被交互式关闭提示阻塞。
- **数据边界**：不新增权限，不改变用户数据目录或垃圾桶的 30 天保留规则。

## 验证

- `pnpm run verify` 全绿（305 项单测，含 typecheck、runtime、站点检查和 build），根树与 Harness 双树安全审计均为 0 漏洞、0 豁免。
- 开发态 E2E 16/16、局域网配对 2/2、`dist:dir`、两种 packaged smoke、打包版 E2E 7/7、市场 offline 1/1 与 real 2/2 全部通过；垃圾桶 UI 和真实 Harness 页面均已核对。
- Windows 发布重跑将验证修复后的 NSIS 残留矩阵；GitHub Release、GitCode 镜像和官网数据在发布后回填。

## English Summary

- Upgrade the bundled kernel from 0.2.0-rc.2 to 0.2.1-alpha.1 and sync the packaged dependency closure.
- Persist the chosen LAN address and validate pairing URLs on multi-interface hosts.
- Match the trash page to the settings design, localize Chinese dates, and report active-session deletion failures accurately.
- Clean up the dsh-desktop process family between Windows NSIS residue scenarios so the next installer cannot block on an interactive close prompt.
