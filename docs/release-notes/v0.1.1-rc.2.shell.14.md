## 本次更新

- **开箱即用与可恢复**：设置页明确展示官方 Harness、数据目录和插件市场状态；社区插件不会随安装包预置，市场需要用户手动安装，安装第三方代码前会显示风险确认。
- **可靠桌面壳**：托盘、设置和错误恢复页统一显示 Harness 状态；Safe Mode 会保留崩溃时的疑似插件，退出隔离后清除旧嫌疑，诊断报告也会记录 profile、市场包和 Safe Mode 原因。
- **更新与配对反馈**：内核检查/安装/健康回滚/恢复内置等结果分别可见；Linux 明确采用手动更新；局域网二维码显示秒级倒计时，过期后自动失效。
- **边界与安全**：运行时仍是锁定的 Node/Electron/Harness 壳，不扩展为 Agent 工作台；安装包继续不含 `dshmarket`，诊断只本地生成，签名与公证仍未启用。

## English Summary

- **Ready-to-use onboarding:** the settings surface shows the official Harness, data directory, and plugin-market state. Community plugins are never bundled; installing the market is manual and requires an explicit third-party code warning.
- **Reliable shell recovery:** tray, settings, and recovery pages share the Harness status. Safe Mode keeps crash suspects until the user exits quarantine, and local diagnostics include profile, market, and Safe Mode context.
- **Actionable updates and pairing:** kernel check/install/health-rollback/restore outcomes are distinct, Linux updates are described as manual, and LAN pairing codes have a live second countdown and expiry state.
- **Scope and security:** this remains a pinned Node/Electron/Harness shell rather than an Agent workbench; diagnostics stay local, `dshmarket` is not a desktop dependency, and signing/notarization remain deferred.
