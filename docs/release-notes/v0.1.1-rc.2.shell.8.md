# dsh-desktop v0.1.1-rc.2.shell.8

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.1-rc.2（未变，壳修订 +8）。

## 本次更新

- **扩展入口可拖动**：右上角 `⋮` 按钮按住即可拖到顺手的角落，位置自动记住；拖拽不会误开菜单，普通点击照常展开。
- **「扩展设置」独立分区**：快捷键、开机启动、启动后隐藏、桌面通知不再嵌在「通用」——设置页左侧新增入口（与通用/模型/插件并列、带图标），排版与 Harness 设置页一致。
- **扩展菜单规整**：连接设备 / 切换全屏 / 打开日志 / 导出诊断 对齐一组，「关于」移至菜单末尾（带分隔线）；入口更名为「扩展入口」（英文 Extensions）。
- **手机扫码配对进设置**：「设置 → 扩展设置」即可点击「连接移动设备」开始配对——手机与电脑同一局域网，扫码 + 一次性配对码进入 Harness Web 界面；配对中可「显示二维码」或「停止共享」，状态实时显示。
- **桌面状态通知补齐验证**（上版功能，本轮补全端到端与打包真机用例）：任务完成/失败/停止或等待确认时，窗口未聚焦即弹出系统通知；点击通知唤回工作区。
- 通知与扩展入口均为本地壳功能：不读取屏幕、不做视觉识别、不上传数据。

## English Summary

- The `⋮` extension entry is now pointer-draggable (position remembered; dragging never opens the menu).
- Desktop preferences moved into a standalone **Extensions** settings section (与通用/模型/插件同级的独立入口, 中文界面为「扩展设置」), styled to match the Harness settings pages.
- The extension menu is trimmed and aligned: Pair device / Fullscreen / Open logs / Diagnostics, with **About last** behind a separator.
- **Connect a mobile device** now lives in Settings → Extensions: start pairing, show the QR code, or stop sharing, with live state.
- Desktop status notices (previous release) gained full end-to-end and packaged coverage this round.
