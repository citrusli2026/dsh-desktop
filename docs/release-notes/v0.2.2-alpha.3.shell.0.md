# dsh-desktop v0.2.2-alpha.3.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.2-alpha.3（由 0.2.2-alpha.2 升级，壳修订归零）。

## 本次更新

- **内核升级 0.2.2-alpha.2 → 0.2.2-alpha.3**（复合版本规则：内核升级把壳修订归零）：manifest pin 与
  32 个 `dsh-*` peer 一起更新，`cordis-plugin-group` 同步到 1.0.6-alpha.2 以满足新内核 app-boot 的
  peer；release-age 豁免按 315 → 302 条重钉，闭包锁文件重生成后重新部署，peer 审计
  `closure satisfied`。两处维护补丁都在新内核上重新落地：账号设置的弹窗回退与 onboarding 守卫仍是
  原来的两处 hunk（按 alpha.3 源码重新生成，`pnpm` 应用时无 `ERR_PNPM_PATCH_FAILED`）；会话垃圾桶的
  生命周期补丁完成上游复审——`dsh-api-session-controller` 的 50 行 diff 全部落在 projection 管线上
  （`onChanged` → `onEventChanged`、`cachedSnapshot` → `snapshot`、列表元数据改走注册句柄），本补丁依赖的
  锚点仍唯一命中；`dsh-client-ui-workspace` 虽然整体 diff 1003 行，但本补丁触碰的 `watchNavigation()`
  与 `clearArchivedCurrent()`/`clearMain()` 两段上游字节相同，选择权释放所读的 `binding.session` /
  `removed` 契约也未变。0.2.2-alpha.3 已登记进 `REVIEWED_KERNELS`。
- **桌面工具菜单收成一行**（社区反馈：展开后比手机屏还长）：每个操作行不再渲染副标题，只保留图标、
  功能名与箭头，行高 52px → 38px，超长标题省略号截断；分组标题（连接／恢复／维护／信息／伴随窗口）
  与顶部说明保留。功能说明仍在设置页可见（飞书连接、安全模式、局域网设置各自的详情文案未动），
  删掉的只是浮层里这 11 条重复描述的双语文案。

## English Summary

- **Kernel 0.2.2-alpha.2 → 0.2.2-alpha.3**: the manifest pin plus 32 `dsh-*` peer ranges moved together,
  `cordis-plugin-group` follows the new app-boot peer (1.0.6-alpha.2), release-age exemptions were re-pinned
  (315 → 302), the closure was regenerated and re-deployed with `audit-harness-peers: closure satisfied`.
  Both maintenance patches were re-reviewed against the new bundles: the account patch is still two hunks
  applied cleanly, and the session-trash patch's anchors and the `binding.session` / `removed` contract it
  reads are unchanged (the host bundle's 50-line diff is projection plumbing only; the workspace bundle's
  navigation block is byte-identical). 0.2.2-alpha.3 is registered in `REVIEWED_KERNELS`.
- **Desktop tools menu is one line per action**: the overlay no longer renders a muted subtitle under each
  label (row height 52px → 38px, long labels ellipsize), while group headers and the panel headline stay.
  Each setting's description remains on its settings page; only the eleven duplicated subtitle strings
  were removed in both locales.
- Verification: `pnpm run verify`; LAN pairing 2/2; offline market e2e 1/1; `dist:dir` followed by the
  packaged and Harness-UI smoke tests.
