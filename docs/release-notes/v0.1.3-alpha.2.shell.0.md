# dsh-desktop v0.1.3-alpha.2.shell.0

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.3-alpha.2（内核升级，壳修订归零）。

## 本次更新

- **内核升级**：随包 Harness 从 0.1.2-rc.1 升至 0.1.3-alpha.2，并同步完整的直接 peer 契约与锁文件。
- **会话持久化兼容**：审查并精确放行新内核所需的 `fs-ext` 文件锁模块；部署后强制使用随包 Node 22 重编译，并执行真实独占锁/解锁探针，避免开发机 Node 24 产物在安装包内因 ABI 不匹配而启动崩溃。
- **模拟器测试收敛**：Android 专用端到端测试会修复 AVD 快照偶发丢失的 `10.0.2.2` 默认路由，再验证扫码配对、前后台切换、共享重启和桌面应用重启后的会话续用；不会修改物理设备网络。
- **边界说明**：局域网配对密钥、设备登记、插件恢复和诊断仍只保存在本机，不上传用户数据。

## 验证

- 239 项单元测试；`verify:full`、16 项开发态 E2E、4 项打包态关键 E2E、真实 Harness UI 和 Safe Mode 坏插件恢复全部通过。
- Android 15 真 Chrome 与移动 WebKit 配对通过；真实插件市场安装及“崩溃 → 自动隔离 → 更新/重启”2/2 通过。
- 根依赖树与 Harness 生产依赖树安全审计均为 0 已知漏洞；发布工作流继续执行 macOS / Windows / Linux 构建、跨版本数据保留、8 资产契约与 attestation。
- GitCode 国内镜像和官网版本数据在三平台产物发布后同步并逐项在线校验。

## English Summary

- Upgraded the bundled Harness kernel to 0.1.3-alpha.2 and aligned its direct peer contracts.
- Rebuilds the new `fs-ext` session-locking addon with the bundled Node 22 runtime and verifies a real lock roundtrip, preventing native ABI startup failures.
- Makes the Android emulator LAN journey self-heal a missing emulator gateway, then verifies pairing and session continuity across proxy and desktop restarts.
- Revalidated real plugin installation, crash quarantine/update recovery, packaged Safe Mode, mobile WebKit, and both dependency security audits.
