# dsh-desktop v0.1.1-rc.2.shell.11

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.1.1-rc.2（未变，壳修订 +1）。

## 本次更新

- **真机修复：插件市场与内核更新不再失败**：安装链全部改用应用内置的 pnpm（打包后从图形界面启动时，系统 PATH 里没有 pnpm，之前必然失败；换 pnpm 大版本还会因 store 不一致报 ERR_PNPM_UNEXPECTED_STORE）。系统代理现在会透传给安装子进程，注册表/余额/更新检查全部有超时且走系统代理。
- **内核更新有反馈了**：「检查新版」后如果没有更新的版本，会明确提示"已是最新版本"；失败也会提示重试，不再沉默。
- **扩展入口全面一致（决策 0023/0028）**：窗口右键菜单补上安全模式；浮层面板的"连接设备"跟随配对状态（显示二维码/停止共享）；四个扩展面——「扩展」菜单、托盘、右键菜单、浮层——全部加入「重启 Harness」，装完插件一键重启生效（就绪状态下会先确认）。
- **扩展设置与浮层瘦身**：浮层只剩动作；说明文字合并进扩展设置，布局收紧。
- **其他真机修复**：macOS 屏幕捕获开启前检查录屏权限（未授权时不再静默截取壁纸）；Windows 通知补齐 App User Model ID（修复可能的收不到通知）；配对二维码窗口在配对失效后自动关闭；崩溃恢复页"以安全模式启动"失败后按钮不再卡死；首次运行 seeding 不再删除用户放置的同名目录。

## English Summary

- Real-machine fix: market installs and the kernel chain run on the bundled pnpm via PATH shims with system-proxy passthrough — no more missing-pnpm or ERR_PNPM_UNEXPECTED_STORE failures; registry, balance, and update lookups are bounded and proxy-aware.
- The kernel "check for newer" action now always answers: "already on the latest version" on success, a retry hint on failure.
- Extension surfaces are consistent again: Safe Mode in the context menu, a state-aware pairing entry in the overlay, and Restart Harness on every surface (app menu, tray, right-click, overlay) — decision 0023 amended by 0028.
- Slimmed overlay panel and extension settings; macOS screen-capture permission gate, Windows notification AUMID, self-closing stale pairing windows, and un-stuck recovery-page buttons.
