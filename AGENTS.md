# AGENTS.md

Guidance for AI agents working in this repo.

## Engineering skills

The mattpocock/skills engineering flow is installed at **user level**
(`~/.zcode/skills/`) and available in every session: `grill-with-docs`
(design interview + ADRs), `to-spec` / `to-tickets`, `implement` (drives
`tdd`), `code-review`, plus `triage`, `diagnosing-bugs`, `research`,
`improve-codebase-architecture`, and others. Ask `/ask-matt` to pick the
right skill or flow for the situation.

## Agent skills

### Issue tracker

Work for this repo is tracked in GitHub Issues (`gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Issues use the five canonical triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root; ADR-style decision records live in `docs/decisions/`. See `docs/agents/domain.md`.
