下载 DeepSeek Harness 桌面版

DSH Desktop 把 DeepSeek Harness 的本地 Web 工作体验封装成可直接启动的桌面应用。当前发布 Windows、macOS 和 Linux 安装包，具体平台以当前 Release 列表为准。

当前版本：请以 GitHub Releases 中最新公开版本为准。

这是社区维护的非官方项目，与 DeepSeek AI 没有隶属、授权或合作关系。下载前请确认你信任公开源码和发布记录。

安装后如何开始

  1. 下载与你系统匹配的安装包并完成安装。
  2. 首次启动后，在 Harness 设置中选择模型服务商并填写 API Key。
  3. 打开新会话开始使用；桌面版会自动管理本地 Harness 进程和数据目录。

下载完整性校验

每个安装包都附带同名的 .sha256 文件。macOS/Linux 可使用 shasum -a 256 -c 文件名.sha256，Windows 可使用 CertUtil -hashfile 文件名 SHA256。校验值应与 Release 中的 checksum 文件一致。
