快速开始

三步开始使用

1

下载并安装

选择你的系统，下载匹配的安装包并完成安装。

2

获取 API Key

在 DeepSeek 开放平台注册账号并创建 API Key（按量计费）。

打开 DeepSeek 开放平台 →
3

粘贴 Key，开始对话

打开 dsh-desktop，在设置中粘贴 Key，即可开始使用。

Windows x64

提供 NSIS 安装程序。首次运行可能出现 Windows SmartScreen 提示，请先确认来源和校验值。

macOS Apple Silicon

提供适用于 M 系列芯片的 DMG。首次打开未签名应用时，请在 Finder 中右键选择“打开”。

Linux amd64

提供 Debian 包，适用于 Debian、Ubuntu、UOS、Deepin 和麒麟等系统。

安装后如何开始

  1. 下载与你系统匹配的安装包并完成安装。
  2. 首次启动后，在 Harness 设置中选择模型服务商并填写 API Key。
  3. 打开新会话开始使用；桌面版会自动管理本地 Harness 进程和数据目录。

下载完整性校验

每个安装包都附带同名的 .sha256 文件。macOS/Linux 可使用 shasum -a 256 -c 文件名.sha256，Windows 可使用 CertUtil -hashfile 文件名 SHA256。校验值应与 Release 中的 checksum 文件一致。
