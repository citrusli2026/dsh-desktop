#特性

为什么用它

无需安装 Node.js

壳内置 Node.js 22 LTS 运行时与 @deepseek-ai/dsh 完整依赖闭包,版本与 SHA-256 逐平台锁定。 下载安装包 → 双击 → 使用,没有任何环境配置;镜像源默认走 npmmirror,国内构建与下载都快。

和命令行共享同一个家

默认共享 ~/.dsh:你在 CLI 里登录过的 API Key、调好的设置、聊过的会话,打开桌面版原样都在; 反过来也一样。壳从不改变 agent 行为 —— 它只负责窗口。

崩溃自愈,指数退避

进程崩溃自动重启(指数退避),错误页可手动重试并查看日志尾部;单实例锁防止多开, 托盘常驻,日志落盘可查。

Windows / Linux 自动更新

基于 electron-updater 的原地自动更新;macOS 因未签名暂不支持自动更新(见决策记录 0004), 每日 dsh-watch 工作流会跟踪上游 npm 新版本并自动发起升级 PR。

#常见问题

macOS 提示"无法打开,因为无法验证开发者"?

macOS 版目前未签名(决策记录 0004)。首次启动请 右键 → 打开,在弹窗中确认即可,之后正常双击启动。

Windows SmartScreen 拦截怎么办?

安装包未购买代码签名证书。点击 "更多信息" → "仍要运行" 即可。安装包由 GitHub Actions 从公开源码构建,可全程审计。

这和 DeepSeek 官方是什么关系?

非官方社区打包,与 DeepSeek AI 无关联。DeepSeek Harness 是 DeepSeek 的商标;本仓库仅在 MIT 许可下再打包 @deepseek-ai/dsh,不改变其任何行为。

我已经在用 npx @deepseek-ai/dsh web,需要迁移吗?

不需要。桌面壳与 CLI 默认共享 ~/.dsh,会话、设置、API Key 直接互通,装完打开就是熟悉的状态。

Apple Silicon 以外的 Mac 可以用吗?

当前仅提供 Apple Silicon(arm64)安装包。Intel Mac 可暂时使用命令行方式 npx @deepseek-ai/dsh web,功能完全一致。
