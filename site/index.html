像成熟桌面工具一样开箱即用，同时保留上游 Harness 的原始能力与可审计边界。

  • Agent 与工具调用行为

扩展功能

扫码，把 Harness 带到手机或平板

桌面端从扩展菜单启动独立的局域网 Web 代理。Harness 继续只监听 loopback，手机浏览器通过一次性配对码获得设备会话。

  1. 扩展 → 通过局域网连接手机 / 平板
  2. 手机与电脑连接同一局域网，扫描二维码
  3. 确认一次性配对码，进入原生 Harness Web 界面

只集成 Web 壳，不需要 Android/iOS；代理与桌面端解耦，可独立产出 Web artifact。

03 / 功能特性

为什么用它

无需安装 Node.js

壳内置 Node.js 22 LTS 运行时与 @deepseek-ai/dsh 完整依赖闭包，版本逐平台锁定。下载安装包 → 双击 → 使用，没有任何环境配置。

独立数据目录，环境隔离

桌面版默认使用 ~/.dsh-desktop：设置、会话、API Key、插件都是独立的一份，安装卸载都不影响你的命令行工作流。需要共享时，设 DSH_HOME=~/.dsh 即可。

原生菜单与 Harness 保持同一种语言

首次启动按系统语言选择中文或英文；之后读取同一份 locale.preference，无需重启即可同步应用菜单、托盘、About、恢复页和对话框。主题也跟随 Harness 设置。

持续守护与可靠更新

崩溃后按预算退避重启，窗口关闭后可驻留托盘，也可从帮助菜单安全重启 Harness。Windows 保留应用内自动更新；未签名的 macOS 检查新版本并打开精确发布页。

渲染层能力默认收敛

保持 Electron 沙箱与上下文隔离、关闭 Node 集成并限制页面导航；媒体、定位、通知、屏幕采集和文件系统等额外权限默认拒绝，未来只能按需显式放行。

问题发生时，带走一份可检查的报告

帮助菜单、托盘和启动失败页都能导出本地诊断报告。报告包含版本、系统状态和有上限的日志尾部，自动遮罩常见密钥与主目录，且绝不自动上传。

04 / 常见问题

常见问题

macOS 提示“无法打开，因为无法验证开发者”？

macOS 版未购买 Apple 开发者证书（决策记录 0004），首次启动请 右键 → 打开。如果仍没有放行选项，且你确认安装包来源可信，可在终端执行：
xattr -dr com.apple.quarantine "/Applications/dsh-desktop.app"open "/Applications/dsh-desktop.app"这会移除下载隔离标记，但不会添加 Apple 签名或公证。

安装包由公开 CI 构建，可用来源证明验证真伪：
gh attestation verify /path/to/dsh-desktop-{ver}-arm64-mac.dmg -R citrusli2026/dsh-electron-shell

Windows SmartScreen 拦截怎么办？

安装包未购买代码签名证书。点击 “更多信息” → “仍要运行” 即可。安装包由 GitHub Actions 从公开源码构建，可全程审计；也可用以下命令验证来源：
gh attestation verify /path/to/dsh-desktop-setup-{ver}.exe -R citrusli2026/dsh-electron-shell

这和 DeepSeek 官方是什么关系？

社区维护的桌面封装：不改写 Harness 行为，数据与配置保持独立。项目与 DeepSeek AI 无隶属、授权或合作关系；DeepSeek Harness 是 DeepSeek 的商标，本仓库仅在 MIT 许可下再打包 @deepseek-ai/dsh，不改变其任何行为。

我在用 npx @deepseek-ai/dsh web，配置会带过来吗？

不会——桌面版是独立环境，数据放在 ~/.dsh-desktop，与 CLI 的 ~/.dsh 互不影响（决策记录 0012）。想沿用 CLI 配置，启动前设 DSH_HOME=~/.dsh 即可。

Apple Silicon 以外的 Mac 可以用吗？

当前仅提供 Apple Silicon（arm64）安装包。Intel Mac 可暂时使用命令行方式 npx @deepseek-ai/dsh web，功能完全一致。

桌面版会申请摄像头、定位或文件系统权限吗？

不会。当前功能不需要这些 Electron Web 权限，桌面壳默认拒绝媒体、定位、通知、采集和文件系统等额外请求；未来如确有需要，必须经过明确的白名单审查。

桌面菜单为什么是中文或英文？

首次启动跟随电脑系统语言；不支持的系统语言默认使用英文。之后在 Harness 中切换语言，应用菜单、托盘和 Shell 对话框会读取同一设置并实时同步。

如何校验下载文件的完整性？

每个安装包都附带同名的 .sha256 校验文件。下载后可用以下命令验证：
shasum -a 256 -c dsh-desktop-{ver}-arm64-mac.dmg.sha256
Windows 用户可用：
CertUtil -hashfile dsh-desktop-setup-{ver}.exe SHA256
校验值应与 .sha256 文件内容一致。也可使用 npx dsh-validate-release 自动校验整个 Release 目录。

如何获取 DeepSeek API Key？

三步即可：
1） 打开 DeepSeek 开放平台 注册账号；
2） 登录后进入「API Keys」页面，点「创建 API Key」，复制生成的 sk- 开头的密钥；
3） 打开 dsh-desktop，在设置中把 Key 粘贴进去即可开始对话。
注意：DeepSeek API 按用量计费，首次使用前需要先充值（平台内最低充值金额即可），充值后立即可用。

GitHub 下载慢或连不上怎么办？

国内网络可优先使用 GitCode 镜像（中文界面自动排在 GitHub 前面；镜像不可用时自动只显示 GitHub）。如仍需走 GitHub，可在下载链接前加社区代理前缀，例如：
https://ghproxy.net/https://github.com/citrusli2026/dsh-electron-shell/releases/download/…公开代理（ghproxy.net / gh-proxy.com / ghfast.top）均为第三方免费服务，可用性不保证，一个不行就换另一个。
