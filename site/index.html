02 / 产品定位

官方 Harness，原样跑进桌面窗口

桌面壳负责安装、启动、恢复和入口；Agent、会话、工具、模型仍由官方 Harness 负责。

01

开箱即用

内置 Node.js 与依赖，安装后直接启动。

02

本地且隔离

只在本机通信，不暴露到局域网；数据默认放在独立的 ~/.dsh-desktop。

03

出错可恢复

安全模式隔离坏插件；错误页可一键升级或禁用可疑插件。

桌面壳负责

  • 窗口、托盘、快捷键与通知
  • 运行时封装、进程守护与更新
  • 安全模式、诊断与权限边界

Harness 继续负责

  • Agent、会话、工具与模型
  • 官方 WebUI 与插件行为
  • 账户配置与官方设置

扩展功能

扫码，把 Harness 带到手机或平板

从「桌面工具」启动局域网 Web 代理，手机与电脑同网后扫码即可进入 Harness。

不需要单独的 Android / iOS 应用。

03 / 社区插件

数千个社区插件，全部由你选择

dsh-desktop 只提供清晰入口和故障恢复支持；社区插件不属于安装包，也不会在首次启动时自动出现。

PLUGIN MARKET

全部按需安装

安装包不内置社区插件；先手动安装 dsh-market，再由你选择其他插件和主题。

01
浏览与一键安装在 Harness「设置 → 插件市场」按分类浏览、安装和更新。
02
装坏了也不怕插件装坏时，错误页可直接升级到最新版或先禁用；安全模式随时兜底。

如何安装：按需在「设置 → 桌面设置 → 插件市场」手动安装 dsh-market，再到 Harness「设置 → 插件市场」手动选择其他插件；首次任务不依赖插件市场。

05 / 桌面能力

你得到的是可靠入口，不是功能堆叠

01

开箱即用

把最容易卡住的运行环境和数据边界处理好，下载后直接进入 Harness。

无需安装 Node.js

内置 Node.js 与锁定依赖，下载安装包即可启动。

独立数据目录，环境隔离

默认使用 ~/.dsh-desktop，不影响命令行；需要共享时再设置 DSH_HOME。

02

日常桌面体验

窗口、托盘、快捷键和通知服务于同一个目标：随时找到并继续你的 Harness。

持续守护与可靠更新

崩溃按预算重启，保留托盘入口；更新失败会回到可用内核。

不用找窗口，快捷键直接唤回

默认 Ctrl/Cmd + Shift + Space，冲突时仍可用托盘和右键。

03

恢复与边界

故障时给出可执行的下一步，同时把权限、数据和上游职责说清楚。

渲染层能力默认收敛

沙箱、上下文隔离和权限拒绝默认开启，桌面通知不读取屏幕。

问题发生时，可检查并恢复

日志和诊断报告在本地生成，自动遮罩常见密钥，不会自动上传。

06 / 支持与边界

先恢复，再反馈；每一步都有入口

01首次安装从下载到第一次启动 02问题恢复先看错误类型和下一步 03提交反馈附版本、平台和脱敏诊断
macOS 提示“无法打开，因为无法验证开发者”？

当前 macOS 安装包尚未签名公证，首次启动请 右键 → 打开。如果仍没有放行选项，且你确认安装包来源可信，可在终端执行：
xattr -dr com.apple.quarantine "/Applications/dsh-desktop.app"open "/Applications/dsh-desktop.app"这会移除下载隔离标记，但不会添加 Apple 签名或公证。

安装包由公开 CI 构建，可用来源证明验证真伪：
gh attestation verify /path/to/dsh-desktop-{ver}-arm64-mac.dmg -R citrusli2026/dsh-desktop

Windows SmartScreen 拦截怎么办？

安装包未购买代码签名证书。点击 “更多信息” → “仍要运行” 即可。安装包由 GitHub Actions 从公开源码构建，可全程审计；也可用以下命令验证来源：
gh attestation verify /path/to/dsh-desktop-setup-{ver}.exe -R citrusli2026/dsh-desktop

这和 DeepSeek 官方是什么关系？

社区维护的桌面封装：不改写 Harness 行为，数据与配置保持独立。项目与 DeepSeek AI 无隶属、授权或合作关系；DeepSeek Harness 是 DeepSeek 的商标，本项目仅在 MIT 许可下再打包 @deepseek-ai/dsh，不改变其任何行为。

我在用 npx @deepseek-ai/dsh web，配置会带过来吗？

不会——桌面版是独立环境，数据放在 ~/.dsh-desktop，与 CLI 的 ~/.dsh 互不影响。想沿用 CLI 配置，启动前设 DSH_HOME=~/.dsh 即可。

桌面版会申请摄像头、定位或文件系统权限吗？

不会。桌面版默认拒绝摄像头、定位、网页通知、屏幕采集和文件系统这类请求；桌面通知是可关闭的本地功能，不读取屏幕，也不上传数据。

如何校验下载文件的完整性？

每个安装包都附带同名的 .sha256 校验文件。下载后可用以下命令验证：
shasum -a 256 -c dsh-desktop-{ver}-arm64-mac.dmg.sha256
Windows 用户可用：
CertUtil -hashfile dsh-desktop-setup-{ver}.exe SHA256
校验值应与 .sha256 文件内容一致。也可使用 npx dsh-validate-release 自动校验整个 Release 目录。

客户端带插件吗？怎么装更多插件？

dsh-desktop 安装包不内置社区插件，所有插件都需要用户手动安装。需要时在 设置 → 桌面设置 → 插件市场 手动安装 dsh-market；装好后打开 Harness「设置 → 插件市场」即可浏览和安装。首次任务不需要插件市场；安全模式会隔离所有第三方插件。

启动失败或插件装坏了怎么办？

应用仍可打开时，先到「设置 → 桌面设置 → 运行体检」查看本地运行环境、数据目录、本地端口与插件状态；联网检查需单独勾选，结果不上传也不自动修复。无法启动时，错误页提供「再次启动」「以安全模式启动」「打开日志目录」「导出诊断报告」；检测到可疑插件时还会逐个列出，可直接「升级」到最新版或「禁用」后重启——禁用只从启动列表移除，不删除文件，可随时在「设置 → 插件」恢复。
