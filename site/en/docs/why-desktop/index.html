WHY DESKTOP

Why DSH Desktop?

The official way to run DeepSeek Harness is npx @deepseek-ai/dsh web in a terminal, then opening a local address in your browser. Functionally it is the same WebUI — DSH Desktop simply packages that WebUI into a dependable native desktop app. The difference: no Node environment to maintain, and no command to remember.

CLI vs desktop client

Capabilitynpx CLI + browserDSH Desktop
Node.js / pnpmInstall and maintain yourselfBundled, pinned Node.js 22 — zero setup
LaunchingOpen a terminal, remember the commandClick the icon, or summon from anywhere with a shortcut
Window & trayOne more browser tabDedicated native window, hides to the system tray
Crash recoveryDiagnose and restart by handRestarts automatically after a crash; error-page retry
Broken pluginsA bad plugin can wedge the WebUIUpdate or disable suspects right from the error page; Safe Mode as the fallback
Data isolationShares ~/.dsh with the CLIOwn ~/.dsh-desktop; share via DSH_HOME if wanted
DiagnosticsRead terminal logs yourselfOne-click health check + exportable sanitized report
UpdatesUpgrade the npm package manuallyWindows in-place auto-update; macOS checks and opens the release page

Who it is for

  • Non-terminal users: download, install, done — no Node.js, npm, or command-line experience required.
  • People who live in Harness daily: tray resident plus a global summon shortcut (default Ctrl/Cmd + Shift + Space).
  • Multi-machine setups: export agent presets as a single .dshpreset file and import them elsewhere.

When the CLI is still the better fit

If you already maintain a Node environment, use Harness over SSH on a server, or want to script it in a pipeline, the official npx @deepseek-ai/dsh web remains the right tool. DSH Desktop is the same kernel in desktop form, not a replacement — the two coexist fine.
