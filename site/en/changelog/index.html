DSH Desktop Changelog

Versions are composite: <dsh kernel>.shell.<shell rev>. The kernel tracks the official @deepseek-ai/dsh package; shell revisions carry desktop-shell fixes and features only. Highlights below; full notes live on each GitHub release page.

v0.1.5-rc.2.shell.4

  • The agent deletion hook now executes for real, ships in packaged builds, quotes paths safely, and rolls back if the trash index cannot be written.
  • Deletion interception is user-controllable from Desktop settings; toggling it restarts Harness so the hook patch is applied or removed.
  • Supervisor spawn errors after readiness enter the normal restart budget instead of silently stopping.
  • Trash index parsing rejects unsafe ids/paths, and public docs now match the actual trash scope.

v0.1.5-rc.2.shell.3

  • The agent deletion hook now executes for real, ships in packaged builds, quotes paths safely, and rolls back if the trash index cannot be written.
  • Deletion interception is user-controllable from Desktop settings; toggling it restarts Harness so the hook patch is applied or removed.
  • Supervisor spawn errors after readiness enter the normal restart budget instead of silently stopping.
  • Trash index parsing rejects unsafe ids/paths, and public docs now match the actual trash scope.

v0.1.5-rc.2.shell.2 （kernel 0.1.5-rc.2）

  • Makes Safe Mode recovery deterministic: crash-time plugin suspects are persisted and drive the disable patch even when the harness crashed before writing the profile manifest.
  • Classifies plugin-vs-kernel API crashes so the error page gives the right guidance instead of a bare error.
  • The one-click health check now validates the bundled Node executable's integrity, and runtime spawn failures get an explicit reinstall hint on the error page and in the diagnostics report.

v0.1.5-rc.2.shell.1 （kernel 0.1.5-rc.2）

  • Classifies plugin-vs-kernel API crashes (runtime type errors inside loader failures) so the error page gives the right guidance instead of a bare error.
  • The one-click health check now validates the bundled Node executable's integrity, catching upgrade-residue and antivirus damage that previously read as healthy.
  • The error page explains runtime spawn failures and calls for a clean reinstall; the diagnostics report records the state for support.

v0.1.5-rc.2.shell.0 （kernel 0.1.5-rc.2）

  • Upgraded the bundled Harness kernel to 0.1.5-rc.2 and realigned all 31 direct peer contracts, the lockfile, and the supply-chain allowlist.
  • Revalidated the full local gate battery, both dependency audit trees (zero known vulnerabilities), and the Android emulator pairing journey.

v0.1.5-rc.1.shell.0 （kernel 0.1.5-rc.1）

  • Upgraded the bundled Harness kernel to 0.1.5-rc.1 and realigned all 31 direct peer contracts, the lockfile, and the supply-chain allowlist.
  • rc.1's WebUI probes the mobile handoff mux at startup; without LAN sharing enabled the probe leaves one console message and the page stays fully functional.
  • Revalidated the full local gate battery, both dependency audit trees (zero known vulnerabilities), and the Android emulator pairing journey.

v0.1.5-alpha.1.shell.1 （kernel 0.1.5-alpha.1）

  • Upgraded the bundled Harness kernel to 0.1.5-alpha.1 and realigned all 31 direct peer contracts, the lockfile, and the supply-chain allowlist.
  • The kernel now locks session files through the prebuilt Node-API @deepseek-ai/node-addon-system; the shell's native-rebuild gate consults the lockfile and rebuilds/probes fs-ext only when the kernel still ships it.
  • Floors vulnerable transitive dependencies (sharp 0.35.4, js-yaml 4.3.2, hono 4.13.5) in both the build chain and the bundled kernel closure; both npm audit trees report zero known vulnerabilities.
  • Revalidated real plugin installation with crash quarantine and update recovery, packaged Safe Mode, the real Harness UI, and the local LAN pairing QR gates.

v0.1.3-alpha.2.shell.0 （kernel 0.1.3-alpha.2）

  • Upgraded the bundled Harness kernel to 0.1.3-alpha.2 and aligned its direct peer contracts.
  • Rebuilds the new fs-ext session-locking addon with the bundled Node 22 runtime and verifies a real lock roundtrip, preventing native ABI startup failures.
  • Makes the Android emulator LAN journey self-heal a missing emulator gateway, then verifies pairing and session continuity across proxy and desktop restarts.
  • Revalidated real plugin installation, crash quarantine/update recovery, packaged Safe Mode, mobile WebKit, and both dependency security audits.
