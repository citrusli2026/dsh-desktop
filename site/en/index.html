DSH DESKTOP / DEEPSEEK HARNESS

DeepSeek Harness as a dependable local desktop app.

DSH Desktop is a community-maintained desktop shell for DeepSeek Harness. Download it, launch it, and keep the local agent workspace in its own desktop window without installing Node.js first.

WINDOWS ACCESS

The menu can hide. Your controls don't.

When Windows hides the title-bar menu, the ⋮ extension entry stays visible for pairing devices, full screen, logs, and diagnostics, with About last. Right-click anywhere in the window or use the system tray for the complete extension fallback.

DESKTOP SHORTCUT

Return without hunting for the window.

Hide dsh-desktop to the tray, then press your summon shortcut from any app to show and focus the workspace. It defaults to Ctrl/Cmd + Shift + Space; if another app owns it, the tray and context menu remain available.

DESKTOP PREFERENCES

Make the shell fit your day.

Open Settings → Extensions to record a summon shortcut, opt into launch at login, start hidden in the tray, and control local status notices. Preferences stay on this device.

DESKTOP NOTIFICATIONS

Finished, failed, or waiting on you — you will know.

While the window is unfocused or tucked into the tray, system notices report sessions completing, failing, stopping, or waiting for your confirmation. They use only the public Harness session and job state; click a notice to summon the workspace back.

What the desktop shell adds

  • Bundled runtime and one-click startup for Windows, macOS, and Linux releases.
  • Native window, tray behavior, lifecycle supervision, and recovery diagnostics.
  • Custom global shortcut, optional launch-at-login, and local status notices from Settings → Extensions.
  • Isolated desktop data at ~/.dsh-desktop, separate from the CLI by default.
  • Sandboxed renderer boundaries while the upstream Harness Web UI remains the source of agent behavior.
