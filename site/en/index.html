DSH DESKTOP / DEEPSEEK HARNESS

A dependable Electron shell for DeepSeek Harness.

DSH Desktop is a community-maintained shell with out-of-the-box support: bundled runtime, isolated local data, familiar desktop entry points, and a recovery path when something fails.

Product boundary: the shell owns the desktop window, tray, runtime, supervision, recovery, updates, and local entry points. The official Harness WebUI still owns agents, sessions, tools, models, and plugin behavior. There is no second workbench, chat surface, or project workspace.

The menu can hide. Your controls don't.

DESKTOP SHORTCUT

Return without hunting for the window.

Hide dsh-desktop to the tray, then press your summon shortcut from any app to show and focus the desktop app. It defaults to Ctrl/Cmd + Shift + Space; if another app owns it, the tray and context menu remain available.

DESKTOP NOTIFICATIONS

Finished, failed, or waiting on you — you will know.

While the window is unfocused or tucked into the tray, system notices report sessions completing, failing, stopping, or waiting for your confirmation. They use only the public Harness session and job state; click a notice to summon the desktop app back.

PLUGIN MARKET

Thousands of community plugins. You choose every one.

Community plugins are not part of the installer and never appear silently on first launch. Manually install dsh-market from Settings → Extensions → Plugin market, then use Harness Settings → Plugin Market to install the plugins you choose. Plugins that need build scripts ask for your approval first, and Safe Mode quarantines third-party plugins if anything misbehaves.

What the desktop shell adds

  • Bundled runtime and one-click startup for Windows, macOS, and Linux releases.
  • Native window, tray behavior, lifecycle supervision, and recovery diagnostics.
  • Custom global shortcut, optional launch-at-login, and local status notices from Settings → Extensions.
  • The community plugin market (dsh-market) with thousands of plugins and themes; install dsh-market manually first, then choose plugins from Harness settings.
  • Isolated desktop data at ~/.dsh-desktop, separate from the CLI by default.
  • Sandboxed renderer boundaries while the upstream Harness Web UI remains the source of agent behavior.

CURRENT RELEASE FOCUS

Reliability you can see and act on.

The current release line closes the desktop shell loop without adding a second Agent product.

  • Clearer state: desktop entry, tray, and settings share the same Harness, Safe Mode, and update status.
  • Direct recovery: retry startup, enter Safe Mode, open logs, or export a local diagnostic report.
  • Explicit plugins: the installer contains no community plugins; dsh-market and every plugin are user-installed.
  • Safer updates: kernel switches use a health boot check and return to the bundled version when needed.
