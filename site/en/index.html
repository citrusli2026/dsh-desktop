DSH DESKTOP / DEEPSEEK HARNESS

A dependable Electron shell for DeepSeek Harness.

DSH Desktop is a community-maintained shell with out-of-the-box support: bundled runtime, isolated local data, familiar desktop entry points, and a recovery path when something fails.

Product boundary: the shell owns the desktop window, tray, runtime, supervision, recovery, updates, and local entry points. The official Harness WebUI still owns agents, sessions, tools, models, and plugin behavior. There is no second workbench, chat surface, or project workspace.

What the desktop shell adds

  • Bundled runtime and one-click startup across Windows, macOS, and Linux.
  • Native window, tray entry, supervision, and recovery diagnostics.
  • Optional shortcut, launch-at-login, and local notices in Settings → Extensions.
  • A manual-first community plugin market with thousands of choices.
  • Isolated ~/.dsh-desktop data and a constrained renderer; Harness remains the source of agent behavior.

CURRENT RELEASE FOCUS

Reliability you can see and act on.

The release line closes the desktop shell loop without adding a second Agent product.

  • Clear state: desktop entry, tray, and settings agree.
  • Direct recovery: retry, Safe Mode, logs, and diagnostics stay close.
  • Explicit plugins: the installer contains no community plugins; every choice is manual.
