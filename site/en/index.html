DSH DESKTOP / DEEPSEEK HARNESS

DeepSeek Harness as a dependable desktop app.

DSH Desktop is a community-maintained desktop app with out-of-the-box support: bundled runtime, isolated local data, familiar desktop entry points, and a recovery path when something fails.

Product boundary: the shell owns the desktop window, tray, runtime, supervision, recovery, updates, and local entry points. What you see and use is the official Harness WebUI — agents, sessions, tools, models, and plugin behavior all come from Harness itself.

What the desktop shell adds

  • Bundled runtime and one-click startup across Windows, macOS, and Linux.
  • Native window, tray entry, supervision, and recovery diagnostics.
  • Optional shortcut, launch-at-login, local notices, and a read-only health check in Settings → Desktop settings.
  • A manual-first community plugin market with thousands of choices.
  • Isolated ~/.dsh-desktop data and a constrained renderer, so desktop permissions stay minimal.

CURRENT RELEASE FOCUS

Everything you delete can come back.

New desktop trash: sessions, presets, plugins, and agent-deleted files land in the trash first, ready to restore.

  • Recoverable: deleted sessions restore with one click in Settings → Trash.
  • Direct recovery: retry, Safe Mode, logs, and diagnostics stay close.
  • Explicit plugins: the installer contains no community plugins; every choice is manual.
