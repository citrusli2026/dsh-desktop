DSH Desktop 常见问题

这里集中回答 DeepSeek Harness 桌面版的安装、平台支持、配置目录和首次启动问题。

DSH Desktop 是 DeepSeek 官方产品吗？

不是。它是社区维护的桌面封装项目，与 DeepSeek AI 没有隶属、授权或合作关系。DeepSeek Harness 及其依赖遵循各自的上游许可和商标政策。

需要安装 Node.js 或运行命令行吗？

发布版内置锁定的 Node.js 运行时和 Harness 依赖，普通用户不需要另行安装 Node.js，也不需要先运行 npx @deepseek-ai/dsh web。

桌面版会读取命令行的配置吗？

默认不会。桌面版使用 ~/.dsh-desktop，命令行通常使用 ~/.dsh。如果需要共享，可以设置 DSH_HOME=~/.dsh，建议先备份。

macOS 提示无法验证开发者怎么办？

当前 macOS 构建可能未经过 Apple 公证。确认安装包来自公开 Release 后，在 Finder 中右键应用选择“打开”。不要从不明来源下载或执行来路不明的终端命令。

Windows SmartScreen 拦截怎么办？

当前 Windows 安装包可能未购买商业代码签名证书。确认来源和校验值后，点击“更多信息 → 仍要运行”。如果不确定文件来源，请停止安装并在 GitHub 仓库提交问题。

Linux 支持哪些系统？

当前提供 amd64 Debian 包，面向 Debian、Ubuntu、UOS、Deepin 和麒麟等系统。不同发行版的系统依赖可能不同，建议优先使用系统软件中心安装。

如何校验安装包没有被篡改？

每个安装包都附带同名 .sha256 文件。macOS/Linux 使用 shasum -a 256 -c 文件名.sha256，Windows 使用 CertUtil -hashfile 文件名 SHA256，再与 Release 中的校验文件比较。

GitHub 下载慢怎么办？

可以打开下载页中的 GitCode 镜像入口。镜像状态会随发布同步变化；如果镜像没有对应文件，请回到 GitHub Release 页面。

如何获取 API Key？

在 DeepSeek 开放平台注册并进入 API Keys 页面创建密钥，然后在 dsh-desktop 的模型设置中粘贴。API 使用按量计费，请先确认账户余额。
