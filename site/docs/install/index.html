DeepSeek Harness 桌面版安装指南

DSH Desktop 的目标是让你不用先配置 Node.js、npm 或终端，就能直接打开 DeepSeek Harness 的可靠本地桌面应用。

三步开始使用

  1. 下载：前往下载页，选择 Windows、macOS 或 Linux 安装包。
  2. 安装：运行安装包并启动 dsh-desktop。应用会自动启动自己的本地 Harness 实例。
  3. 配置：在 Harness 设置中选择模型服务商，粘贴 API Key，然后创建第一个会话。

各平台首次启动

Windows

运行 NSIS 安装程序即可。如果 Windows SmartScreen 显示“Windows 已保护你的电脑”，确认下载来源后点击“更多信息 → 仍要运行”。

macOS Apple Silicon

打开 DMG，将应用拖入 Applications。首次启动如提示无法验证开发者，请在 Finder 中右键应用，选择“打开”，再确认一次。

Linux amd64

双击 Debian 包，或使用系统软件中心安装。安装后从应用菜单启动 dsh-desktop。

配置 DeepSeek API Key

登录 DeepSeek 开放平台，进入 API Keys 创建密钥。回到 dsh-desktop，在模型或服务商设置中粘贴密钥。API 按用量计费，使用前请确认账户余额和平台价格。

产品边界与社区插件

dsh-desktop 是可靠的 Electron 壳，加上开箱即用支持：它负责桌面窗口、托盘、内置运行时、进程守护和恢复入口；Harness 继续负责 Agent、会话、工具、模型和插件行为。它不另做一套 Agent 工作台、聊天界面或项目空间。

安装包和首次启动都不包含社区插件，也不会静默安装。需要时先在 Harness「设置 → 扩展设置 → 插件市场」手动安装 dsh-market，再从 Harness「设置 → 插件市场」选择你需要的插件。插件可能下载并运行社区代码或构建脚本，请在安装前确认来源并主动授权。

如何快速唤回窗口？

窗口收进系统托盘后，在任意应用中按自己的唤起快捷键，dsh-desktop 会显示并获得焦点；默认组合键为 Ctrl/Cmd + Shift + Space。若组合键已被其他软件占用，仍可从系统托盘或窗口右键菜单打开。

设置桌面偏好

打开 dsh-desktop 的「设置 → 扩展设置」即可重新录入唤起快捷键、选择是否开机启动、是否启动后隐藏到托盘，以及是否接收本地桌面通知。开机启动在 Windows/macOS 可用，默认关闭；通知只在窗口未聚焦时出现，不读取屏幕内容，也不会上传数据。

桌面版和命令行数据是否共享？

默认不共享。桌面版使用独立的 ~/.dsh-desktop 数据目录，不会覆盖命令行使用的 ~/.dsh。如果你确实要共享配置，可以在启动前设置 DSH_HOME=~/.dsh，但建议先备份数据。

启动失败怎么办？

先确认安装包完整、磁盘可写，并检查系统是否拦截了本地进程或 loopback 连接。错误页提供「再次启动」「以安全模式启动」「打开日志目录」「导出诊断报告」四个入口；安全模式会隔离用户插件，不删除或移动你的文件。提交问题时请同时提供版本号、平台和脱敏后的诊断报告。更多首次启动问题见常见问题。
