为什么选择 DSH Desktop 桌面版？

DeepSeek Harness 官方用法是在终端运行 npx @deepseek-ai/dsh web，然后在浏览器里打开本地地址。功能上完全一致——DSH Desktop 就是把这个 WebUI 稳定地搬进一个原生桌面应用。区别在于：你不用再维护 Node 环境，也不用记住那行命令。

命令行 vs 桌面客户端

能力npx 命令行 + 浏览器DSH Desktop
Node.js / pnpm 环境需要自装并维护版本内置锁定版本的 Node.js 22，零配置
启动方式打开终端，记住并输入命令双击图标，或用快捷键从任意应用唤起
窗口与托盘占用一个浏览器标签页独立原生窗口，可收进系统托盘常驻
崩溃恢复进程挂了需要自己排查重启崩溃后自动重启，错误页一键重试
坏插件隔离插件出错可能卡死整个 WebUI错误页一键升级或禁用可疑插件；安全模式兜底隔离
数据隔离与 CLI 共用 ~/.dsh独立 ~/.dsh-desktop，可经 DSH_HOME 共享
诊断自己翻终端日志一键体检 + 可导出的脱敏诊断报告
更新手动升级 npm 包Windows 原地自动更新；macOS 检查并直达发布页

适合谁

  • 不想折腾终端的用户：下载安装即用，不需要 Node.js、npm 或任何命令行基础。
  • 把 Harness 当日常工作台的人：托盘常驻 + 全局唤起快捷键（默认 Ctrl/Cmd + Shift + Space），随手打开、随手收起。
  • 多台机器或会给同事部署的人：Agent 预设可导出为单个 .dshpreset 文件迁移。

什么时候用命令行更好

如果你已经在维护 Node 环境、需要在服务器上通过 SSH 使用 Harness、或想把 Harness 嵌入自己的脚本流水线，官方 npx @deepseek-ai/dsh web 仍然是正确选择。DSH Desktop 是同一内核的桌面形态，不是替代品；两者可以共存。
