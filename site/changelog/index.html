DSH Desktop 更新日志

版本号是复合形式 <dsh 内核版本>.shell.<壳修订>：内核随官方 @deepseek-ai/dsh 升级，壳修订只包含桌面壳自身的修复与功能。以下节选近期版本要点，完整说明见各版本 Release 页。

v0.1.2-rc.1.shell.2 （2026-09-04，内核 0.1.2-rc.1）

  • 主界面新增四步首次成功引导（运行环境 → 工作区 → 模型 → 首条任务），「扩展入口 / 扩展设置」更名为「桌面工具 / 桌面设置」。
  • 新增一键运行体检：随包运行时、数据目录、loopback、Profile、插件与版本，默认本地只读。
  • Windows 升级清理阶段容忍文件锁，避免升级被偶发的占用中断。

v0.1.2-rc.1.shell.0 （2026-09-04，内核升级）

  • 内核升级并锁定官方 @deepseek-ai/dsh 0.1.2-rc.1：会话加载、长会话内存与密集实时消息渲染优化。
  • 依赖安全下限：锁定 fast-uri、qs、@xmldom/xmldom 安全版本，双锁文件官方审计零已知漏洞。

v0.1.2-alpha.4.shell.3 （2026-09-02）

  • 插件安装反馈：手动安装 dsh-market 展示准备、下载、验证与重启阶段，失败原因分类脱敏、可重试。
  • 跨版本升级验证：三平台发布前对上一公开版本做真实升级，用户 Profile 内容逐项保持不变。
  • Windows 升级改为旧程序静默卸载后原位安装，不再 NSIS 覆盖。

v0.1.2-alpha.3.shell.0 （2026-09-01）

  • 扩展浮层按「连接 → 恢复 → 信息」重排，连接移动设备成为首要操作。
  • 扩展设置分区展示，修复窄窗口下局域网、快捷键、插件市场与安全模式的布局问题。

v0.1.2-alpha.2.shell.0 （2026-08-31）

  • 设置页收敛：安全模式提升到首屏，低频工具收进「更多壳工具」。
  • 官网轮播统一为真实应用截图，中英文、明暗主题一一对应。

v0.1.1-rc.2.shell.15 （2026-08-30）

  • 启动状态反馈：展示正在启动 / 等待就绪 / 自动重试 / 运行中 / 恢复暂停，含尝试次数。
  • 托盘、设置页、加载页与诊断报告使用同一套生命周期状态。

更早版本的说明见 GitHub Releases。
