DSH Desktop 更新日志

版本号是复合形式 <dsh 内核版本>.shell.<壳修订>：内核随官方 @deepseek-ai/dsh 升级，壳修订只包含桌面壳自身的修复与功能。以下节选近期版本要点，完整说明见各版本 Release 页。

v0.2.1-alpha.1.shell.4 （内核 0.2.1-alpha.1）

  • 局域网配对稳定性：发布当前主线已实现的多网卡 URL 校验与网卡选择持久化，避免配对二维码锚定回环地址后失败。
  • 故障恢复：发布当前主线已实现的 Windows 运行文件、sharp 原生模块和插件内核不匹配诊断；Safe Mode/插件恢复路径保持可用。
  • 发布链路：移除会触发已知失效 GitCode v5 回补的自动步骤，改由 GitCode v2 国内镜像流程在发布后逐资产匿名校验。
  • 供应链安全：将 sharp 提升到 0.35.5，修复 GHSA-wq5f-xc86-pv6w；sprintf-js 的 CVE-2026-97058 目前无上游修复，审计仅对这一条公告做了显式临时忽略。
  • 边界说明：内置官方 Harness 内核版本不变；不新增权限，不改变用户数据目录或垃圾桶保留规则。

v0.2.1-alpha.1.shell.3 （内核 0.2.1-alpha.1）

  • 内核升级：从 0.2.0-rc.2 升级到 0.2.1-alpha.1，同步桌面壳的插件兼容版本与随包依赖。
  • 局域网配对：记住用户选择的网络地址；多网卡环境中先核对二维码所指向的地址，避免二维码指向不可用网卡。
  • 桌面垃圾桶：卡片、操作按钮和页签与设置页视觉风格一致；中文界面按中文格式显示日期，运行中的会话被拒绝删除时显示正确原因。
  • Windows 发布门禁：每个 NSIS 残留场景验证后停止 dsh-desktop 进程族并运行对应卸载器，清除注册安装路径，避免下一场景的旧版静默安装器阻塞。
  • 数据边界：不新增权限，不改变用户数据目录或垃圾桶的 30 天保留规则。

v0.2.0-rc.2.shell.0 （内核 0.2.0-rc.2）

  • 内核升级：从 0.2.0-rc.1 升级到 0.2.0-rc.2，壳侧同步 34 个 dsh-* peer pin，并按 lockfile 实际解析结果维护 release-age 豁免。Windows x64、macOS arm64 与 Linux 安装包由发布流水线构建。
  • 登录授权适配：登录授权链接在每次新授权尝试时自动于系统浏览器打开，并保留当前主题；补丁按 rc.2 组件重新生成并通过真实打包 E2E。
  • 插件兼容性：随内核继续在安装时校验插件 peer 兼容性；插件不兼容时会明确拒绝并说明原因。社区市场版本需声明支持 0.2.0 内核，等待兼容版本跨过随包 pnpm 的发布年龄门槛后会自动解析到兼容版本。
  • 安全边界：不新增权限，不改变用户数据目录；插件风险豁免仍需用户明确选择。

v0.2.0-rc.1.shell.0 （内核 0.2.0-rc.1）

  • 内核升级 0.1.7-rc.2 → 0.2.0-rc.1：跟随上游 0.2.0 线的首个候选版。壳侧闭包同步 34 个 dsh-* peer 钉、release-age 豁免清单重钉 229 项；登录授权自动打开补丁按新版本语义原样重建（上游 SignInDialog 仍未内置该能力）。
  • 插件安装更安全（内核新行为）：0.2.0 内核在插件安装时强制校验 peer 兼容性——与内核版本不匹配的旧插件会被明确拒绝并给出解释与风险豁免指引，不再静默装上后在运行时崩溃。社区插件市场（dshmarket）需 1.66.4 及以上版本才与本内核声明兼容；配套的 pnpm 11 供应链策略（新包发布满 24 小时才参与解析）意味着市场安装将在 1.66.4 发布满 24 小时后（2026-09-29 晚）自动恢复，此前安装会显示可重试的分类失败说明，无需用户操作。
  • 升级与隔离契约延续：跨版本升级冒烟（设置/数据保留断言）、插件损坏隔离（Safe Mode）在新内核上复验通过。

v0.1.7-rc.2.shell.2 （内核 0.1.7-rc.2）

  • 多网卡多二维码完全支持（#65）：LAN 配对不再只展示主网卡一个地址。桌面端与移动配对代理现在为机器上每一个私有地址（物理网卡 + Tailscale/ZeroTier 等虚拟网卡）各起一套完整监听，扫码窗口为每个地址渲染独立二维码并标注类型（局域网 / VPN 虚拟网卡）——手机接哪个网段都能扫到对应的码。
  • 网卡选择与覆盖：配对面板新增网卡勾选，勾选结果持久化；高级场景可用 DSH_LAN_IP 环境变量覆盖（单地址、逗号分隔多地址、或 0.0.0.0/all 全网卡通配）。
  • 代理稳定性修复：多地址监听重构中遗留的循环嵌套导致升级（WebSocket）处理器与 SSE 长连接超时配置未应用到实际监听的服务，已修复；双地址冒烟 + 双 LAN E2E 全绿。
  • 边界说明：LAN 配对仅限局域网/虚拟局域网内使用，令牌一次性配对、不穿透公网，不上传任何数据。

更早版本的说明见 GitHub Releases。
